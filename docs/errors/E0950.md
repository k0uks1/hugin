# E0950: module that `programOf` cannot stratify

A relation of the module that `programOf` reifies depends on itself through a negation or an aggregate,
so the module has no strata.

## Example

```hugin fail=E0950
%use "std/semantics".
%use "std/quote".
game : Type = { pos : type, move : pos -> pos -> rel }.
play (g : game) = {
  win : g.pos -> rel.
  win X :- g.move X Y, not win Y.
}.
p : game -> program = programOf play.
```

## Why this is an error

The meaning of a program with negation and aggregates is its perfect model (see
[`std/strata`](https://k0uks1.github.io/hugin/reference/std/strata.html)): the strata are read in order,
and a negation or an aggregate reads the complete facts of the strata below it. A relation that depends
on itself through a negation or an aggregate has no stratum below the one it is in: here, whether `win`
holds of a position depends on whether it holds of the next one. The compiler checks the strata of a
module where it is instantiated (E0601); `programOf` reads the body of a functor, which may have no
instance, so it checks the strata itself.

## How to fix it

Define the relation without a negation of itself, for example from the parameter's relation, which is
complete:

```hugin
%use "std/semantics".
%use "std/quote".
game : Type = { pos : type, move : pos -> pos -> rel, %complete move }.
play (g : game) = {
  stuck : g.pos -> rel.
  stuck X :- g.move _ X, not g.move X _.
}.
p : game -> program = programOf play.
```
