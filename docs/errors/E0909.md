# E0909: staging failure

Meta code spliced into an object item does not compute to object code.

## Example

```hugin fail=E0909 elaborate
rate : int -> int.
price : int -> rel.
price (rate 1).
```

## Why this is an error

Object items are staged by evaluating the meta code they splice. What remains must be object code.
Here `rate` is a postulate, a function without a definition, so `rate 1` is a stuck application. An
object type that nothing determines (an implicit type argument of a family) is not this error but
[E0206](E0206.md), reported where the item is elaborated.

The diagnostic shows the stuck code. Stuck code can share a value, as a function that uses its argument
twice does, so that its size is small but written out it would be very large; the diagnostic then shows
its first part and `…` for the rest.

## How to fix it

Define the function:

```hugin elaborate
rate : int -> int = [x] x + 1.
price : int -> rel.
price (rate 1).
```
