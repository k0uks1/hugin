# E0916: type binder used in a definition

The definition of `f : (x : A) -> B = e.` uses `x`, a binder of its declared type.

## Example

```hugin fail=E0916
double : (x : int) -> int = x * 2.
r : int -> rel.
r (double 21).
```

## Why this is an error

The binders of a type (`(x : A) -> B`) name the argument within the type only: they do not scope over
the definition after `=`. To use the argument in the definition, make it a parameter of the definition
header, `f (x : A) : B = e.`; `hugin fix` does this rewriting. A lambda (`= [x] e`) works too.

## How to fix it

Make the argument a parameter of the definition:

```hugin
double (x : int) : int = x * 2.
r : int -> rel.
r (double 21).
```
