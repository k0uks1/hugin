# E0902: stage error

A meta value is used as object code, or object code where a meta value is needed.

## Example

```hugin fail=E0902 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
level : int -> rel.
level zero.
```

## Why this is an error

Object code (rules, atoms, terms of object types) runs after compilation; meta values (numbers computed
at compile time, inductive values, functions) exist only during compilation. Object code can splice meta
values that compute to object code of the right type, and meta code cannot inspect object code. A meta
value is used as object code directly if its type has a *lifting*: a primitive value (`int`, `float`,
`string`) becomes a literal, and a value of a shared data type (declared `T ā : data.`, such as the
`list` and `option` of the standard library) becomes the object term of the same constructors. A meta
inductive family such as `nat` above has no lifting; declared `nat : data.`, it would have one.

## How to fix it

Use an object literal:

```hugin elaborate
level : int -> rel.
level 0.
```
