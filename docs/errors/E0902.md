# E0902: stage error

A compile-time value is used as object code, or object code where a compile-time value is needed.

## Example

```hugin fail=E0902 new-meta
nat : Type.
zero : nat.
suc : nat -> nat.
q : int -> rel.
q zero.
```

## Why this is an error

Object code (rules, atoms, terms of object types) runs after compilation; meta values (numbers computed
at compile time, inductive values, functions) exist only during compilation. Object code can splice meta
values that compute to object code of the right type, and meta code cannot inspect object code.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
q : int -> rel.
q 0.
```
