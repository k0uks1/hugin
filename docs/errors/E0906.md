# E0906: unknown or missing field

A record lacks a field its type requires, or a field is selected that the record type does not have.

## Example

```hugin fail=E0906 new-meta
point : Type = { x : int, y : int }.
origin : point = { x = 0, y = 0 }.
z = origin.z.
```

## Why this is an error

Record types list their fields; a record value must give each of them exactly once, and a projection
must name one of them.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
point : Type = { x : int, y : int }.
origin : point = { x = 0, y = 0 }.
y = origin.y.
```
