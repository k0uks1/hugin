# E1001: not a directive

A directive `%d a₁ … aₙ.` names a meta function whose application does not have the type of a
directive.

## Example

```hugin fail=E1001
twice : int -> int.
twice X = X + X.
%twice 3.
```

## Why this is an error

A directive is the application of a meta function (see
[Directives](https://k0uks1.github.io/hugin/directives.html)), and the type of the application says what
it changes (its *footprint*):

* `decl`: the declaration of one object constant (a *local* directive, like `%input r.`);
* `list item` (also `item`, `rule`, `list rule`): items added where the directive stands (*additive*);
* `module -> module`: the rules and queries of the file, rewritten (*module-wide*).

An application of another type, such as `int`, changes nothing the compiler knows of.

## How to fix it

Apply a directive, or declare the meta function with a directive's type:

```hugin
node : type.
edge : node -> node -> rel.
loop : term -> list item.
loop N = '{ edge $N $N. }.
a : node.
%loop a.
```
