# E0914: invalid inductive declaration

A declaration cannot be defined by clauses, or an inductive declaration is malformed.

## Example

```hugin fail=E0914 elaborate
edge : int -> int -> rel.
edge X Y = X.
```

## Why this is an error

Clauses `f p ... = t` define meta functions; relations are defined by rules (`:-`) and constructors are
declared by their types.

A constructor's argument must also live in its family's universe (predicativity). An implicit argument
at a [parameter](https://k0uks1.github.io/hugin/reference/meta/families.html#parameters) of the family,
a leading argument that every constructor keeps fixed, is exempt; one at an index is not. A constructor
that does not keep an argument fixed turns it into an index, and the implicit arguments of the other
constructors at that position count again:

```hugin fail=E0914 elaborate
rep : Type -> Type.
wrap : A -> rep A.
deep : rep (rep int) = wrap (wrap 1).
unit : rep int.
```

Here `deep` needs `rep` in the universe of `wrap`'s implicit `A : Type`, which is exempt while `A` is a
parameter of `rep`; `unit` returns `rep int`, which makes it an index.

## How to fix it

Define the relation by a rule:

```hugin elaborate
edge : int -> int -> rel.
edge X Y :- X = 1, Y = 2.
```

Or give the constructor that fixes the argument a family of its own, so that the argument of `rep` stays a
parameter:

```hugin elaborate
rep : Type -> Type.
wrap : A -> rep A.
deep : rep (rep int) = wrap (wrap 1).
unitRep : Type.
unit : unitRep.
```
