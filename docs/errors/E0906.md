# E0906: unknown or missing field

A record lacks a field its type requires, or a field is selected that the record type does not have.

## Example

```hugin fail=E0906 elaborate
point : Type = { x : int, y : int }.
origin : point = { x = 0, y = 0 }.
z = origin.z.
```

## Why this is an error

Record types list their fields; a record value must give each of them exactly once, and a projection
must name one of them. A module ascribed a signature has only the fields of the signature: a declaration
that a file's `%export` leaves out, or that an ascription `m : S = e.` does not list, is not a field of the module, and
selecting it or naming it in `%use m (…)` is this error. See
[Modules](https://k0uks1.github.io/hugin/modules.html#signatures).

## How to fix it

Select a field of the record type:

```hugin elaborate
point : Type = { x : int, y : int }.
origin : point = { x = 0, y = 0 }.
y = origin.y.
```
