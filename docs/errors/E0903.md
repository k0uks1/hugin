# E0903: cannot infer

Elaboration cannot determine a type or an implicit argument.

## Example

```hugin fail=E0903 new-meta
ident = [x] x.
```

## Why this is an error

Types and implicit arguments are inferred by unification. When nothing in the program determines them,
a type annotation is needed.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
ident : int -> int = [x] x.
```
