The meta level is a total, dependently typed functional language that runs at compile time. This lesson shows only what is needed to read proofs: a proposition is a type, and a proof is a value of that type.

0 + n ≡ n is the type eq (plus 0 n) n of std/eq, whose only value is refl, a proof that both sides are the same. zeroPlus is a function by clauses, one for each constructor of nat: for 0, both sides evaluate to 0; for N + 1, the recursive call proves the statement for N, and cong suc adds one to both sides. A recursive function is a proof by induction.

The compiler accepts a function only if it is total: its clauses must cover every case (a missing case is an error), and each recursive call must be on a smaller argument. Without these checks bad : (n : nat) -> 0 ≡ 1 could be "proved" by a function that never returns.

empty is a type with no values; a function into it is a refutation. In noLoop () the pattern () says there is no value to match: 1 ≡ 0 has no proof, since 1 and 0 are different constructors.

%opaque marks definitions as theorems: they are checked once and never unfolded afterwards. The tour marks every theorem this way, and the result pane lists the opaque definitions it checked.
