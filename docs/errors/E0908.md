# E0908: object-level function

A relation or constructor takes an object type or a function as an argument.

## Example

```hugin fail=E0908 elaborate
r : type -> rel.
```

## Why this is an error

The object level is first order: relations and constructors take values of base types, object types and
fact types, not types or functions. Abstract over them at the meta level instead.

## How to fix it

```hugin elaborate
r : int -> rel.
```
