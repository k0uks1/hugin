# E0801: invalid input fact

An input fact is not ground, not well-typed, or not for an input relation.

## Example

```hugin fail=E0801
edge : int -> int -> rel.
%input edge.
?- edge X Y.
```

```facts
edge 1 "two".
```

## Why this is an error

Input files (`--facts`) contain ground facts of relations declared `%input` (or `%open`), with
arguments of the declared column types.

## How to fix it

```hugin
edge : int -> int -> rel.
%input edge.
?- edge X Y.
```

```facts
edge 1 2.
```
