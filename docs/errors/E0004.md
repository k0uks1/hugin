# E0004: malformed item

The item does not have the shape of a declaration, definition, rule, query or directive.

## Example

```hugin fail=E0004
(ready) : rel.
```

## Why this is an error

A declaration has the form `name param* : type.` and a definition `name param* = expr.`: the head is a
lowercase name followed by parameters (`X` or `(name : type)`). Requirements such as `%complete` belong
in a signature, and a clause of a formula function has exactly one head.

## How to fix it

Write the name of the declaration without parentheses:

```hugin
ready : rel.
```
