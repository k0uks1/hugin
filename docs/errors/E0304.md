# E0304: no common label

A projected label is missing from some member of the projected type.

## Example

```hugin fail=E0304
pt : type = { x : int, y : int }.
qt : type = { x : int, z : int }.
both : pt | qt -> rel.
ys : int -> rel.
ys V :- both P, V = P.y.
```

## Why this is an error

Projecting `P.y` from a value of a union type requires every member of the union to have the label
`y`, since the value may be of any of them.

## How to fix it

Project a label that every member has:

```hugin
pt : type = { x : int, y : int }.
qt : type = { x : int, z : int }.
both : pt | qt -> rel.
xs : int -> rel.
xs V :- both P, V = P.x.
```
