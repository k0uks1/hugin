# E1002: directive not applicable to a declaration

A directive written before a declaration (the prefix form `%d a₁ … aₙ DECL`) applies to that
declaration, so `d a₁ … aₙ` must have type `decl -> decl`.

## Example

```hugin fail=E1002
node : type.
edge : node -> node -> rel.
%output edge
seen : node -> rel.
```

## Why this is an error

In the prefix form the declaration that follows is the directive's last argument (docs/REDESIGN.md
§7.1): `%output` before `seen : node -> rel.` makes `seen` an output relation. Here `%output edge`
already names its declaration, so it has type `decl` and cannot take another one. Often a `.` is
missing at the end of the directive.

## How to fix it

End the directive with `.`, or leave out its argument to apply it to the declaration that follows:

```hugin
node : type.
edge : node -> node -> rel.
%output edge.
%output
seen : node -> rel.
```
