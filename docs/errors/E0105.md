# E0105: forward reference

A meta definition refers to itself or to a later definition.

## Example

```hugin fail=E0105
twice : int = once * 2.
once : int = 1.
```

## Why this is an error

The meta level is evaluated in order and has no recursion: a meta definition may only refer to the
definitions before it. Recursion belongs to the object level, in rules.

## How to fix it

```hugin
once : int = 1.
twice : int = once * 2.
```
