# E0201: runtime value used at compile time

**Retired** (redesign step B3): the meta level reports object code used where a compile-time value is needed as [E0902](E0902.md).

An object variable occurs where a meta value is required.

## Example

```hugin fail=E0201 ignore
item : (name : string) -> (price : int) -> rel.
listed : item -> rel.
scale : int -> int = [x : int] x * 2.
doubled : int -> rel.
doubled P :- listed I, P = scale I.price.
```

## Why this is an error

Meta definitions are evaluated at compile time, before any fact exists. An object variable such as `I`
stands for values that are only known when the rules run, so it cannot be the argument of a meta
function, a type, a record or anything else that the meta level must know. Use object-level arithmetic
or a formula function instead.

## How to fix it

```hugin ignore
item : (name : string) -> (price : int) -> rel.
listed : item -> rel.
doubled : int -> rel.
doubled P :- listed I, P = I.price * 2.
```
