# E0202: stage error

A meta value is used at the object level where it cannot be spliced, or an object entity where a meta value of another kind is required.

## Example

```hugin fail=E0202
item : (name : string) -> (price : int) -> rel.
listed : item -> rel.
cheap : item -> prop = [I] I.price < 10.
dear : item -> rel.
dear I :- listed I, not cheap I.
```

## Why this is an error

The object level (terms, formulas, rules) and the meta level (definitions, modules, functions) are
separate stages. A meta value can appear in object code only where it denotes object code of the right
kind: a term where a term is expected, a formula where a formula is expected. Here `not` is applied to
a use of the formula function `cheap`, which may expand to any formula, not only a relation atom. Other
forms of this error: an aggregate that is not bound to a variable, and staged code that does not have
the shape of a term or formula.

## How to fix it

```hugin
item : (name : string) -> (price : int) -> rel.
listed : item -> rel.
cheap : item -> prop = [I] I.price < 10.
dear : item -> rel.
dear I :- listed I, I.price >= 10.
```
