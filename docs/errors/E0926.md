# E0926: no implicit argument of that name

An implicit argument given by name, `f {x := e}`, or an implicit pattern `{x := p}`, names no implicit
binder that it can give.

## Example

```hugin fail=E0926
%use "std/nat".
eq : {A : Type} -> A -> A -> Type.
refl : {A : Type} -> {x : A} -> eq x x.
trans : {A : Type} -> {x y z : A} -> eq x y -> eq y z -> eq x z.
trans refl Q = Q.
four : eq (plus 2 2) 4 = trans {middle := 4} refl refl.
```

## Why this is an error

At an application, `{x := e}` gives the implicit argument whose binder is named `x`, one of those before
the function's next explicit argument; the implicit arguments before it are inferred. In a clause,
`{x := p}` matches an implicit argument of the function, one before the argument after the clause's last
explicit pattern; in a constructor pattern, an implicit argument of the constructor. `{x := e}` is
allowed only in these places. See
[Functions and implicit arguments](https://k0uks1.github.io/hugin/reference/meta/functions.html#implicit-arguments-by-name)
and [Clauses](https://k0uks1.github.io/hugin/reference/meta/clauses.html#implicit-patterns). Here the
binders of `trans` are named `A`, `x`, `y` and `z`, and none is named `middle`.

## How to fix it

Use the name of the binder, as the declaration of the function writes it:

```hugin
%use "std/nat".
eq : {A : Type} -> A -> A -> Type.
refl : {A : Type} -> {x : A} -> eq x x.
trans : {A : Type} -> {x y z : A} -> eq x y -> eq y z -> eq x z.
trans refl Q = Q.
four : eq (plus 2 2) 4 = trans {y := 4} refl refl.
```
