# W0006: unreachable clause

A clause of a meta function is never used.

## Example

```hugin fail=W0006 new-meta
nat : Type.
zero : nat.
suc : nat -> nat.
isZero : nat -> int.
isZero zero = 1.
isZero N = 0.
isZero (suc N) = 0.
```

## Why this is reported

The clauses before it cover every case it matches, so it can be removed. Lint name:
`unreachable_clauses`.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
nat : Type.
zero : nat.
suc : nat -> nat.
isZero : nat -> int.
isZero zero = 1.
isZero (suc N) = 0.
```
