# E0940: `programOf` without its libraries

`programOf P`, a form of the code bridge `std/quote`, builds a program value of the bundled library
`std/semantics`, and the program does not load both.

## Example

```hugin fail=E0940
%use "std/semantics".
graph2 : Type = { node : type, edge : node -> node -> rel }.
tc (g : graph2) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
}.
p : graph2 -> program = programOf tc.
```

## Why this is an error

`programOf` reifies the rules of a module as data of the families of `std/semantics` (`program`,
`crule`, `cat`, …), with the input test `inputOf` (see
[`std/quote`](https://k0uks1.github.io/hugin/reference/std/quote.html)). Like `match H :` with `std/eq`,
the form uses the library's declarations, so a program that uses it loads the library.

## How to fix it

Load the code bridge and the semantics:

```hugin
%use "std/semantics".
%use "std/quote".
graph2 : Type = { node : type, edge : node -> node -> rel }.
tc (g : graph2) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
}.
p : graph2 -> program = programOf tc.
```
