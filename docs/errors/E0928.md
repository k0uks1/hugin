# E0928: cannot rewrite

`rewrite h in e` needs an equation `h : eq a b`, an expected type, and an occurrence of `a` in it.

## Example

```hugin fail=E0928
%use "std/eq".
%use "std/nat".
zeroPlus : (n : nat) -> eq (plus 0 n) n.
zeroPlus 0 = refl.
zeroPlus (N + 1) = cong suc (zeroPlus N).
same : (n : nat) -> eq n n.
same N = rewrite zeroPlus N in refl.
```

## Why this is an error

`rewrite h in e` abstracts the left side `a` of the equation in the normal form of the expected type,
checks `e` with `b` in its place, and elaborates to `subst P (sym h) e` (see
[`match` and `rewrite`](https://k0uks1.github.io/hugin/reference/meta/match.html#rewrite)). It reports
this error if

- the type of `h` is not `eq a b` of `std/eq`;
- `a` does not occur in the expected type (there is nothing to rewrite);
- the expected type is not known, as for the right-hand side of a local definition without a type.

Here the goal `eq N N` does not contain `plus 0 N`, the left side of `zeroPlus N`.

## How to fix it

Rewrite with an equation whose left side occurs in the goal, or from right to left with `sym`; here
no rewrite is needed:

```hugin
%use "std/eq".
%use "std/nat".
same : (n : nat) -> eq n n.
same N = refl.
```
