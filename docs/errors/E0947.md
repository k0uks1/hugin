# E0947: judgment without a database

A judgment `P ⊢ r t̄` without a database `[e]` is outside the type of a declaration, and no variable `d`
is in scope.

## Example

```hugin fail=E0947
%use "std/graph".
%use "std/semantics".
pathOf (g : graph) (x : g.node) (y : g.node) : Type = tc g ⊢ path x y.
```

## Why this is an error

A judgment is about the facts a program derives from a database of input facts. In the type of a
declaration, a judgment without `[e]` uses the database `d`, which becomes an implicit binder `{d : db}`
of the declaration (see
[`std/semantics`](https://k0uks1.github.io/hugin/reference/std/semantics.html#generalisation)). Elsewhere,
such as in the definition of `pathOf`, it uses the variable `d` in scope, and there is none.

## How to fix it

Give the database, or take it as a parameter named `d`:

```hugin
%use "std/graph".
%use "std/semantics".
pathOf (g : graph) (e : db) (x : g.node) (y : g.node) : Type = tc g ⊢[e] path x y.
```
