# W0003: unused definition

A top-level meta function, formula function or constant is never referenced.

## Example

```hugin fail=W0003
limit : int = 10.
cap : int -> rel.
cap 1.
```

## Why this is reported

A definition that nothing uses has no effect on the program, and is often left over from an
earlier version. Lint name: `unused_definitions`.

## How to fix it

Use the definition, or remove it:

```hugin
limit : int = 10.
cap : int -> rel.
cap limit.
```
