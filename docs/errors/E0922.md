# E0922: subtyping edge into a shared type

A subtyping edge `τ <: T` or a refinement `a : type <: T` names a shared data type `T`.

## Example

```hugin fail=E0922
color : data.
red : color.
paint : type.
paint <: color.
```

## Why this is an error

A shared data type is closed (the reference,
[families](https://k0uks1.github.io/hugin/meta/families.html#shared-data)): its constructors are fixed
by its declaration, because its meta side is an inductive family, whose clauses are checked for
coverage against exactly these constructors, and `T.lift` must have a case for every value. An edge
would add object values that have no meta counterpart.

## How to fix it

Add the constructor to the shared type, or declare an open object type for the extended set of values:

```hugin
colorish : type.
red : colorish.
paint : type.
paint <: colorish.
```
