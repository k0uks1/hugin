# E0604: invalid %terminates directive

A `%terminates` measure does not justify termination.

## Example

```hugin fail=E0604
counter : int -> rel.
%terminates N (counter N).
counter 0.
counter M :- counter N, M = N + 1.
```

## Why this is an error

A `%terminates` directive names a measure. Every recursive call must decrease it, it must be bounded
(an anchor bounds it from below), and a measured relation may only call relations of its component that
have a measure too. `--explain-termination` shows the accepted justifications.

## How to fix it

```hugin
counter : int -> rel.
counter 0.
counter M :- counter N, N < 10, M = N + 1.
```
