# Error index

Every diagnostic of the compiler has a code: `E` for errors, `W` for warnings. This appendix has one page
per code, with an example that reports it and an example that fixes it; `hugin explain <code>` prints the
same text. Retired codes are kept so that old links stay valid.

The pages are made from `docs/errors/<code>.md` when the book is built (see `reference/README.md`); the
list below is generated.
