# E0905: not a function

A term that is not a function is applied to an argument.

## Example

```hugin fail=E0905 elaborate
limit : int = 3.
twice = limit 2.
```

## Why this is an error

Only functions take arguments; here `limit` is a compile-time integer. (A relation applied to too many
arguments is reported as E0207.)

## How to fix it

```hugin elaborate
limit : int = 3.
twice = limit * 2.
```
