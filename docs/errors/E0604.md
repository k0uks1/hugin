# E0604: invalid %terminates directive

A `%terminates` measure does not justify termination.

## Example

```hugin fail=E0604
counter : int -> rel.
%terminates N (counter N).
counter 0.
counter M :- counter N, M = N + 1.
```

## Why this is an error

A `%terminates` directive names a measure for guarded induction. Every recursive call must decrease
the measure, the measure of every head must lie in a finite set (its anchor), and a measured relation
may only call relations of its component that have a measure too. Here nothing bounds `N`.
`--explain-termination` shows the arguments that the compiler tried. See
[Termination](https://k0uks1.github.io/hugin/object/termination.html#declared-measures).

## How to fix it

Bound the counter by a comparison, and leave the measure to the compiler:

```hugin
counter : int -> rel.
counter 0.
counter M :- counter N, N < 10, M = N + 1.
```
