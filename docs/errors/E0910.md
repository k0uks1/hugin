# E0910: invalid rule head

A rule head is not an atom applied to all of its columns.

## Example

```hugin fail=E0910 new-meta
edge : int -> int -> rel.
edge 1.
```

## Why this is an error

A rule head must be an atom (a relation applied to all of its columns) or a constructor term, since it
derives a fact.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
edge : int -> int -> rel.
edge 1 2.
```
