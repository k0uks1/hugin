# E0003: invalid literal

An object integer literal does not fit into 64 bits, or a string contains an invalid escape.

## Example

```hugin fail=E0003
reading : int -> rel.
reading 99999999999999999999.
```

## Why this is an error

Object integers are signed 64-bit values, so a literal of object code must lie between
−9223372036854775808 and 9223372036854775807. A literal of the meta level may be larger: a numeral of a
nat-like meta family, such as the prelude's `nat`, and a meta integer of type `int` are unbounded (a meta
integer used as object code must fit, [E0927](E0927.md)). In strings, the valid escapes are `\"`, `\\`, `\n`, `\t` and `\u{...}` with the
code point of a Unicode scalar value.

## How to fix it

Use a literal within the range of `int`:

```hugin
reading : int -> rel.
reading 9223372036854775807.
```
