# E0305: undefined join

A projected label has types in different members whose join is undefined.

## Example

```hugin fail=E0305
%fact pt : type = { x : int, y : int }.
st : type = { x : string, y : int }.
mixed : pt | st -> rel.
xs : int -> rel.
xs V :- mixed P, V = P.x.
```

## Why this is an error

The type of a projection from a union is the join of the label's types in the members. Different base
types such as `int` and `string` have no join.

## How to fix it

```hugin
%fact pt : type = { x : int, y : int }.
st : type = { x : string, y : int }.
mixed : pt | st -> rel.
ys : int -> rel.
ys V :- mixed P, V = P.y.
```
