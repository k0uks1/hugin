# E0406: data constructor used as a relation

A constructor or struct declared without `%fact` is read, derived or named as a relation.

## Example

```hugin fail=E0406
shape : type.
square : int -> shape.
sides : int -> rel.
sides N :- square N.
```

## Why this is an error

A constructor or struct declared without `%fact` is a data constructor: it builds values, which are
not facts of a relation. It cannot be read by an atom (in a body, a negation, an aggregate or a query),
derived by a rule head, named by a directive, or passed where a relation is expected; terms built with it
are allowed everywhere. Declare it `%fact c : t1 -> ... -> a.` to read its facts, and require
`%fact c : ...` in a signature to read a constructor field inside a functor.

## How to fix it

```hugin
shape : type.
%fact square : int -> shape.
square 4.
sides : int -> rel.
sides N :- square N.
```
