# E0003: invalid literal

An integer literal does not fit into 64 bits, or a string contains an invalid escape.

## Example

```hugin fail=E0003
reading : int -> rel.
reading 99999999999999999999.
```

## Why this is an error

Integers are signed 64-bit values, so a literal must lie between −9223372036854775808 and
9223372036854775807. In strings, the valid escapes are `\"`, `\\`, `\n`, `\t` and `\u{...}` with the
code point of a Unicode scalar value.

## How to fix it

Use a literal within the range of `int`:

```hugin
reading : int -> rel.
reading 9223372036854775807.
```
