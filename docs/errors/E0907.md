# E0907: not supported by the new meta level yet

The program uses a construct that the new meta level does not support yet.

## Example

```hugin fail=E0907 new-meta
m = { p : int -> rel. }.
```

## Why this is an error

The new meta level is being built in steps; module bodies, among others, are ported in a later step.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
p : int -> rel.
```
