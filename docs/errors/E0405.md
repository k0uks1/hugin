# E0405: invalid ascription

An ascription `(t : T)` does not select members of the type of `t`.

## Example

```hugin fail=E0405
person : type.
student : string -> person.
staff : type.
teacher : string -> rel.
teacher <: staff.
member : type = student | teacher.
everyone : member -> rel.
p : person -> rel.
p P :- everyone (P : person).
```

## Why this is an error

An ascription is a checked downcast: `T` must be a subtype of the type of `t`, and only types of facts
can be tested at run time. Here `person` has members (other constructors) that `member` does not.

## How to fix it

```hugin
person : type.
student : string -> person.
staff : type.
teacher : string -> rel.
teacher <: staff.
member : type = student | teacher.
everyone : member -> rel.
p : student -> rel.
p P :- everyone (P : student).
```
