# E0202: stage error

A meta value is used at the object level where it cannot be spliced, or an object entity where a meta value of another kind is required.

## Example

```hugin fail=E0202
road : int -> int -> rel.
n : int = 3.
q : int -> rel.
q X :- road X Y, n Y.
```

## Why this is an error

The object level (terms, formulas, rules) and the meta level (definitions, modules, functions) are
separate stages. A meta value can appear in object code only where it denotes object code of the right
kind: a term where a term is expected, a formula where a formula is expected. Here `n` is an integer
constant, which is a term, but it is applied as if it were a relation. Other forms of this error:
`not` applied to something that is not a relation atom, an aggregate that is not bound to a variable,
and splices of meta values that are not code.

## How to fix it

```hugin
road : int -> int -> rel.
n : int = 3.
q : int -> rel.
q X :- road X Y, Y = n.
```
