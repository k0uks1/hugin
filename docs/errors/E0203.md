# E0203: meta type mismatch

**Retired** (redesign step B3): meta-level type errors are reported as [E0901](E0901.md) (mismatched types) or [E0204](E0204.md) (signature mismatch).

A meta expression does not have the expected meta type.

## Example

```hugin fail=E0203 ignore
graph : Type = { node : type, edge : node -> node -> rel }.
tc (g : graph) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
  path X Z :- g.edge X Y, path Y Z.
}.
city : type.
road : city -> city -> rel.
weight : city -> city -> int -> rel.
bad = tc { node = city, edge = weight }.
```

## Why this is an error

Arguments of functors and meta functions are checked against their parameters' meta types. Here the
field `edge` of `graph` is a binary relation over `node`, but `weight` has three columns.

## How to fix it

```hugin ignore
graph : Type = { node : type, edge : node -> node -> rel }.
tc (g : graph) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
  path X Z :- g.edge X Y, path Y Z.
}.
city : type.
road : city -> city -> rel.
weight : city -> city -> int -> rel.
ok = tc { node = city, edge = road }.
```
