# E0603: growing component without a termination argument

A recursive component with a constructive rule has no termination argument.

## Example

```hugin fail=E0603
nat : int -> rel.
nat 0.
nat M :- nat N, M = N + 1.
```

## Why this is an error

A constructive rule creates new values (arithmetic, constructor terms), so its recursive component could
have an infinite fixed point. It must terminate by descent along derivations (an argument decreases from
premise to conclusion in every cycle) or by guarded induction (a measure decreases along every recursive
call and is bound by a guard), or have a `%partial` relation. `--explain-termination` shows the accepted
arguments.

## How to fix it

```hugin
nat : int -> rel.
nat 0.
nat M :- nat N, N < 100, M = N + 1.
```
