# E0923: shared data declaration out of place

A shared data declaration `T ā : data.` is written in a module body (or a `where` block), or a
constructor of a shared type is declared outside the file that declares the type.

## Example

```hugin fail=E0923
single : A -> list A.
```

## Why this is an error

Shared data types are declared at the top level of a file, with all their constructors (the reference,
[families](https://k0uks1.github.io/hugin/meta/families.html#shared-data)). The meta side of a shared
type is an inductive family, which is closed: coverage of clauses and the derived `T.lift` and
`T.reify` depend on its complete set of constructors. The prelude's `list` and `option` are shared, so a
program cannot add constructors to them. In a module body, the meta side would be generative (a fresh
family per instance of a functor), which the meta level does not support.

## How to fix it

Define a function instead of a constructor, or declare a type of your own:

```hugin
single : A -> list A.
single X = [X].
```
