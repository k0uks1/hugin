# E0303: projection on a type that is not closed

A projection or update is applied to a value whose type is not closed.

## Example

```hugin fail=E0303
shape : type.
circle : (r : int) -> shape.
anyshape : shape -> rel.
radius : int -> rel.
radius R :- anyshape S, R = S.r.
```

## Why this is an error

Projection `x.l` and update `(x with l = t)` need to know every member of the type of `x`: a fact type
or a union of fact types. An open type may gain constructors in other places, which might not have the
label. Projections and updates also apply only to variables.

## How to fix it

```hugin
shape : type.
circle : (r : int) -> shape.
circles : circle -> rel.
radius : int -> rel.
radius R :- circles S, R = S.r.
```
