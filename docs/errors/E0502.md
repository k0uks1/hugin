# E0502: call without applicable mode

**Retired** (redesign step C3): relations have no modes (REDESIGN D2, §3.5). `%demand r +i -o` generates ordinary demand rules; a call whose inputs are not bound makes its generated demand rule not range-restricted (E0501, noted as an expansion of `%demand`). 

A moded relation or primitive is called without any applicable mode.

## Example

```hugin fail=E0502 ignore
fib : (n : int) -> (f : int) -> rel.
%mode fib +n -f.
fib 0 0.
call : int -> rel.
call F :- fib N F.
```

## Why this is an error

A relation with `%mode` declarations is evaluated on demand: each call must bind the inputs of one of
its modes. Bind the input arguments with earlier formulas in the body.

## How to fix it

```hugin ignore
fib : (n : int) -> (f : int) -> rel.
%mode fib +n -f.
fib 0 0.
call : int -> rel.
call F :- fib 0 F.
```
