# E0956: run outside the certified fragment

`hugin run --certify` checks runs of function-free Datalog with negated atoms and comparisons, the
fragment that the proof export exports, and a rule or a value of the run is outside it.

## Example

```hugin fail=E0956 certify
%use "std/certify".
step : int -> rel.
step 0.
step (X + 1) :- step X, X < 3.
```

## Why this is an error

A certified run reifies the program and its facts as values of
[`std/semantics`](https://k0uks1.github.io/hugin/reference/std/semantics.html) and checks them in the
meta level, which needs the program in a form whose meaning the semantics models and whose checking it
can prove correct. The certified fragment is that of the proof export (reference: object/io, "Proof
export"): atoms whose arguments are variables and constants, negated atoms and comparisons of variables
and constants. Arithmetic and constructor terms in heads and atoms, aggregates, disjunctions, bound
columns and `as` are outside it, and so are values that are facts or infinities. A rule outside the
fragment is not exported, so the facts it derives have no derivation for the checker.

## How to fix it

Give what the rule computes as data, here the successor relation as input facts:

```hugin certify
%use "std/certify".
succ : int -> int -> rel.
%input succ.
step : int -> rel.
step 0.
step Y :- step X, succ X Y.
```

```facts
succ 0 1.
succ 1 2.
succ 2 3.
```
