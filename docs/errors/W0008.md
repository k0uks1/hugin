# W0008: constant used as a formula

A constant without arguments, such as `false`, stands as a formula in the body of a rule or a query.

## Example

```hugin fail=W0008
setting : type.
verbose : setting.
logged : string -> rel.
logged "start" :- verbose.
```

## Why this is reported

A constant is a term, and a term is a fact once a head or an input file builds it (reference: rules,
"Constants as formulas"). A constant used as a formula is an existence check: it holds if the constant is
a fact. It does not test a value. With the shared `bool`, `p :- false.` derives `p` as soon as any fact
contains `false`, for example a fact `enabled 3 false`. That is allowed, but it is almost never what the
rule means. Lint name: `constant_formulas`.

## How to fix it

Keep the setting in a relation and match the value in an atom of it:

```hugin
setting : type.
verbose : setting.
quiet : setting.
active : setting -> rel.
active verbose.
logged : string -> rel.
logged "start" :- active verbose.
```
