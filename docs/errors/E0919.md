# E0919: quote without a reflective type

A quote `'( … )` is written where no reflective type (`term`, `quoted A`, `formula`, `rule`, `item`,
`module`, `sym`, `decl`, `measure`, `list rule`) is expected: the expected type is another one, or it is
not known.

## Example

```hugin fail=E0919
%use "std/reflect".
p : int -> rel.
q : int -> rel.
r = '( p X :- q X ).
```

## Why this is an error

The content of a quote is ordinary object syntax (see
[Reflection](https://k0uks1.github.io/hugin/reference/reflection.html)), and the same text can denote data of
several categories: `'( p X )` is a formula, a rule (the fact `p X`), an item or a module of one item.
The expected type decides which, so a quote needs one. Here the definition `r` has no declared type, and
its right-hand side is inferred. An item `$e.` expects reflected items, so `$'( … ).` needs no type.

## How to fix it

Declare the type of the definition, or ascribe the quote:

```hugin
%use "std/reflect".
p : int -> rel.
q : int -> rel.
r : rule = '( p X :- q X ).
s = ('( p X :- q X ) : rule).
$[r, s].
```
