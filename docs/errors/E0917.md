# E0917: invalid quoted syntax

A quote `'( … )` (or a directive's argument, which is quoted implicitly) uses a form of object syntax
that has no reflective representation, its content is not of the category the expected type needs, or
a hole is in the wrong place.

## Example

```hugin fail=E0917
%use "std/reflect".
p : int -> rel.
q : int -> int -> rel.
r : rule = '( p X :- q X ([y] y) ).
```

## Why this is an error

A quote denotes data of the reflective types of `std/reflect` (see
[Reflection](https://k0uks1.github.io/hugin/reference/reflection.html)), which represent object variables,
literals, object constants applied to terms, arithmetic, `as`, ascriptions, projections, updates,
comparisons, `not`, `,`, `;` and aggregates. Other forms (lambdas, records) have no representation, and
an ascription cannot be a quoted pattern, since its object type is code, which a pattern cannot match.

The expected type gives the category of the content: a `module` (or `list rule`) quote holds items with
their periods, as in a file; a `rule` or `item` quote holds one item (its period is optional); a
`formula`, `term`, `quoted A`, `sym`, `decl` or `measure` quote holds one of them, without `:-` or a
period. A list of formulas or terms is a meta list of quotes (`['( p X ), '( q X )]`). A quote directly
inside quoted syntax and a typed hole `?` are not object syntax; a quote may stand inside a hole,
`'( p $(f '( X )) )`.

Holes exist only inside a quote; outside, `$x` is the staging splice. Inside a quote:

* `$..Xs` stands for a sequence, such as the arguments of an atom, the body of a rule or the items of a
  module, and cannot stand for a single element;
* in a pattern, `$..Xs` must end its sequence;
* a hole in a pattern binds a variable (`$X`) or matches anything (`$_`);
* the arguments of a higher-order hole `$F[V]` in a pattern are variables bound by an enclosing
  aggregate.

Without the prelude (`--no-prelude`), `std/reflect` is not part of the compilation unless the program
imports it.

## How to fix it

Write the code in the represented forms, for example with a variable instead of a lambda:

```hugin
%use "std/reflect".
p : int -> rel.
q : int -> int -> rel.
r : rule = '( p X :- q X X ).
```
