# E0602: negation or aggregation over an incomplete relation

A rule or query negates or aggregates over a relation whose facts may be incomplete.

## Example

```hugin fail=E0602
user : type.
login : user -> rel.
%open login.
known : user -> rel.
%input known.
inactive : user -> rel.
inactive U :- known U, not login U.
```

## Why this is an error

The absence of a fact of an incomplete relation means "unknown", not "false". A relation is incomplete
if it is `%open`, or depends positively on an incomplete relation. Queries may mention
incomplete relations only positively.

## How to fix it

```hugin
user : type.
login : user -> rel.
%input login.
known : user -> rel.
%input known.
inactive : user -> rel.
inactive U :- known U, not login U.
```
