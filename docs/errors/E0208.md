# E0208: unsatisfied requirement

A relation passed to a functor does not satisfy `%complete` required by the signature.

## Example

```hugin fail=E0208
complete_graph : Type = { node : type, edge : node -> node -> rel, %complete edge }.
sources (g : complete_graph) = {
  source : g.node -> rel.
  source N :- g.edge N _, not g.edge _ N.
}.
city : type.
road : city -> city -> rel.
%open road.
s = sources { node = city, edge = road }.
```

## Why this is an error

A signature can require that a relation field is complete (`%complete edge`), because the functor
negates or aggregates over it. The relation passed must satisfy the requirement: an `%open` relation is
not complete.

## How to fix it

Pass a complete relation:

```hugin
complete_graph : Type = { node : type, edge : node -> node -> rel, %complete edge }.
sources (g : complete_graph) = {
  source : g.node -> rel.
  source N :- g.edge N _, not g.edge _ N.
}.
city : type.
road : city -> city -> rel.
s = sources { node = city, edge = road }.
```
