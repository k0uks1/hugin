# E0404: ill-formed declaration

A type declaration or subtyping edge is not well formed.

## Example

```hugin fail=E0404
shape : type.
circle : int -> shape.
small : type <: circle.
```

## Why this is an error

A refinement `a : type <: b.` must refine a base type or another refinement, without cycles. A
subtyping edge `c <: t` needs an open type `t`, and a fact type or an open type `c`; in a functor's body,
a type that the parameter gives is neither. The members of a union in the type of a column must be
types of facts and must not overlap. The error is reported at the edge, the refinement or the declaration
of the column. See [Object types](https://k0uks1.github.io/hugin/reference/object/types.html#open-types).

## How to fix it

Refine a base type or another refinement:

```hugin
size : type <: int.
small : type <: size.
```
