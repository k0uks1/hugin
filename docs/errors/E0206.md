# E0206: cannot infer type argument

An implicit type parameter or family type argument is not determined by first-order matching.

## Example

```hugin fail=E0206
list A : type.
nil : list A.
size : list A -> rel.
size nil.
?- size nil.
```

## Why this is an error

Type arguments of families are inferred from the types of their uses. When nothing fixes them, as for
`nil` here, an ascription `(nil : list int)` states the type.

## How to fix it

Ascribe the type of `nil`:

```hugin
list A : type.
nil : list A.
size : list A -> rel.
size (nil : list int).
?- size (nil : list int).
```
