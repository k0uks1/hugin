The library std/semantics defines the meaning of Datalog in the meta level: an inductive family derives p d a whose values are the derivations of the fact a by the program p from the input facts d. A derivation is a tree: a rule at the root, and a derivation of each atom of its body below it. The facts that have a derivation are exactly the facts of the least model; the library proves this (least, derivesModel).

The judgment tc G ⊢ path x y is notation for that type: the program of tc G derives path x y. In a declaration's type, G is a free variable, so the statement is about every graph, and the database of input facts is an implicit argument, so it is about every input. x y : G.node are nodes of that graph.

Rule names are the constructors of derivations. path.1 E is a derivation by the first rule of path (path X Y :- g.edge X Y), given a derivation E of its one body atom. G.edge has no rules in tc: its facts are inputs.

Rule names are also patterns. hops matches on the last rule of a derivation and counts its edges: it is an ordinary function on derivations. The clauses must cover every rule that can derive the goal's relation, as for any inductive type.

What is proved. For every graph and every set of input facts: an edge gives a path, and two edges give a path. What is trusted. That the engine computes the facts that derives defines; this is one statement for all programs (the last lesson returns to it).
