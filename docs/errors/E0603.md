# E0603: growing component without a termination argument

A recursive component with a constructive rule has no termination argument.

## Example

```hugin fail=E0603
nat : int -> rel.
nat 0.
nat M :- nat N, M = N + 1.
```

## Why this is an error

A constructive rule creates new values, by arithmetic or by building constructor terms, so its
recursive component could have an infinite fixed point. The component must terminate by descent along
derivations, where an argument decreases from premise to conclusion in every cycle, or by guarded
induction, where a measure decreases along every recursive call and stays in a finite set. A program for
which the compiler finds neither argument is rejected; there is no limit on the number of rounds.
Recursion through arithmetic that keeps only the best value per key can use a bound column (`min int` or
`max int`) instead. `--explain-termination` shows the arguments that the compiler tried. A rule that
builds a constructor term in its head is also evaluated in the component of the constructor, so it
counts there too. See [Termination](https://k0uks1.github.io/hugin/reference/object/termination.html).

The directive `%partial`, which marked possibly infinite relations, no longer exists.

## How to fix it

Bound the counter by a comparison:

```hugin
nat : int -> rel.
nat 0.
nat M :- nat N, N < 100, M = N + 1.
```
