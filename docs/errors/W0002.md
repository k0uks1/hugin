# W0002: singleton variable

A variable occurs only once in a rule.

## Example

```hugin fail=W0002
edge : int -> int -> rel.
%input edge.
src : int -> rel.
src X :- edge X Y.
```

## Why this is reported

A variable that occurs once constrains nothing, which often means a misspelt variable. Write `_` (or a
name starting with `_`) when this is intended; the quick fix does so. Lint name: `singleton_variables`.

## How to fix it

Write `_` for the variable that is not used:

```hugin
edge : int -> int -> rel.
%input edge.
src : int -> rel.
src X :- edge X _.
```
