A common use of Datalog is program analysis, where a large graph is abstracted to a smaller one and the analysis runs on the abstraction. The functor coarse computes both: reached, reachability from the seeds on the graph, and areached, reachability on the graph of abstract nodes, where alpha x a places node x in abstract node a.

sound states that the abstraction over-approximates: if x is reached and alpha x b, then b is reached on the coarse graph. It needs a hypothesis, placed: every reached node has some abstraction. Without it the statement is false (a reached node with no abstract node would break the induction), so it is an argument of the theorem. The proof is by induction on the derivation of reached x, and uses the rule aedge.1 to lift each concrete edge.

safe is the form an analysis uses: an abstract node the analysis does not reach contains no reached node. In the run, no is not reached, so no city in Norway is reachable from Berlin.

What is proved. For every abstraction and every input database that satisfies placed: every abstract node of a reached node is reached. What is trusted. Adequacy. The hypothesis placed is about the input; it is not checked for the facts of a particular run.
