# E0904: universe inconsistency

A type is used as an element of itself.

## Example

```hugin fail=E0904 elaborate
u : Type = Type.
bad : u = u.
```

## Why this is an error

`Type : Type` would make the meta level inconsistent (Girard's paradox), so `Type` lives in a higher
universe than the types it contains.

## How to fix it

```hugin elaborate
u : Type = int.
ok : u = 1.
```
