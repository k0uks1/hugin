# E0005: unclosed delimiter

An opening parenthesis, bracket, brace or quote is not closed before the item ends.

## Example

```hugin fail=E0005
edge : int -> int -> rel.
reach : int -> rel.
reach Y :- edge (1 Y.
```

## Why this is an error

Parentheses `( )`, brackets `[ ]`, braces `{ }` and quotes `'( )` come in pairs. The parser looks for the
closing delimiter within the item; if the item ends first (at its period, at the start of the next item
in column 0, or at the end of the file), the delimiter is reported as unclosed, with a label on the
opening one. The rest of the item is parsed as if the delimiter were there, but the item is not
elaborated: the parser cannot know where the delimiter was meant to go. `hugin fix` inserts it at the end
of the last token before the item ends.

## How to fix it

Close the delimiter where it was meant to end:

```hugin
edge : int -> int -> rel.
reach : int -> rel.
reach Y :- edge 1 Y.
```
