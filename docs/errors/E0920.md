# E0920: constructor argument that cannot be shared

A constructor of a shared data type (declared `T ā : data.`) has an argument whose type exists at one
stage only: a function type, a universe, object code `⇑A`, `sym`, a relation, a meta type or an object
type that is not shared, or a type variable that is not a parameter of `T`.

## Example

```hugin fail=E0920
nat : Type.
zero : nat.
suc : nat -> nat.
shape : data.
circle : (radius : nat) -> shape.
```

## Why this is an error

A shared data declaration declares the type at both stages (see [Inductive
families](https://k0uks1.github.io/hugin/meta/families.html#shared-data)): a meta inductive family, whose
values exist at compile time, and an object family, whose terms are facts at run time. A value can be
lifted into object code, or reified into `term` data, constructor by constructor, so each argument must
exist at both stages too. That holds for the parameters of `T`, for `int`, `float` and `string`, and for
shared types; `nat` above is a meta type, which has no object counterpart.

## How to fix it

Declare the argument's type as a shared type as well (or use a base type):

```hugin
nat : data.
zero : nat.
suc : nat -> nat.
shape : data.
circle : (radius : nat) -> shape.
```

If the type is meant for one stage only, declare it as an object type (`shape : type.`) or a meta type
(`shape : Type.`).
