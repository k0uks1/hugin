# E0907: not supported by the meta level

The program uses a construct that the meta level does not support where it is written.

## Example

```hugin fail=E0907 elaborate
m = { small : type <: int. }.
```

## Why this is an error

Some constructs are not supported in a module body: refinements, families of object constants,
reflected items `$e.`, and additive or module-wide directives. They are allowed at the top level of a
file. See [Modules](https://k0uks1.github.io/hugin/modules.html#module-bodies).

## How to fix it

Declare the construct at the top level of a file:

```hugin elaborate
small : type <: int.
```
