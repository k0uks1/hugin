# E0961: judgment over a program with negation or aggregates, without `std/strata`

A judgment `P ⊢ r t̄` is about a program that has a negation or an aggregate in the body of a rule, and the
file does not load `std/strata`.

## Example

```hugin fail=E0961
%use "std/semantics".
city : type. berlin, paris : city.
road : city -> city -> rel.
closed : city -> rel.
m = {
  open : city -> rel.
  open X :- road X _, not closed X.
}.
openIn : {x : city} -> m ⊢ open x -> Type.
openIn _ = Type.
```

## Why this is an error

Over a program with a negation or an aggregate, the judgment notation stands for the *stratum-local*
judgment of [`std/strata`](https://k0uks1.github.io/hugin/reference/std/strata.html#the-stratum-local-judgment):
the derivations of the last stratum with a rule for `r`, read with the facts of the strata below it, in
which negated atoms and aggregates are premises. It is not `derives` of `std/semantics`, the positive
fragment, in which a rule with a negation or an aggregate never fires: `m ⊢ open berlin` would have no
derivation there, although running `m` with a road from berlin derives `m.open berlin`, and a proof could
contradict the run. The stratum-local judgment is defined in `std/strata`, which the file must load.

## How to fix it

Load `std/strata`:

```hugin
%use "std/semantics".
%use "std/strata".
city : type. berlin, paris : city.
road : city -> city -> rel.
closed : city -> rel.
m = {
  open : city -> rel.
  open X :- road X _, not closed X.
}.
openIn : {x : city} -> m ⊢ open x -> Type.
openIn _ = Type.
```
