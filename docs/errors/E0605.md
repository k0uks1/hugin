# E0605: invalid bound column

A bound column type `min τ` or `max τ` is used where it is not allowed.

## Example

```hugin fail=E0605
node : type.
first : (d : min int) -> (v : node) -> rel.
```

## Why this is an error

A relation with a bound column keeps one value per key, the least for `min` and the greatest for
`max`; the key is the other columns. So a bound column must be the last column of a relation
declaration, not of a constructor, a struct or a signature field, and its type must be `int` or a
refinement of `int`. See [Bound columns](https://k0uks1.github.io/hugin/object/bound-columns.html).

## How to fix it

Make the bound column the last column:

```hugin
node : type.
first : (v : node) -> (d : min int) -> rel.
```
