# E0941: `programOf` of something that is not a module

The argument of `programOf` is not a functor, a functor applied to arguments, or a module.

## Example

```hugin fail=E0941
%use "std/semantics".
%use "std/quote".
three : int = 3.
p : program = programOf three.
```

## Why this is an error

`programOf P` reifies the rules of a module body (see
[`std/quote`](https://k0uks1.github.io/hugin/reference/std/quote.html)): the body of a functor `f`
(giving a function from its parameters to programs), of a functor applied to arguments `f a`, or of a
module, which is the program of the application that made it. Other values have no rules.

`programOf here`, the program of the current file, is not available yet: the file's rules are elaborated
after its meta definitions, so a definition cannot read them.

## How to fix it

Give a functor, an application or a module:

```hugin
%use "std/semantics".
%use "std/quote".
graph2 : Type = { node : type, edge : node -> node -> rel }.
tc (g : graph2) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
}.
p : graph2 -> program = programOf tc.
```
