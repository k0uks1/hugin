# E0913: non-positive occurrence

An inductive family occurs to the left of an arrow in one of its constructors, or in a constructor of
another family of its mutual block.

## Example

```hugin fail=E0913 elaborate
bad : Type.
mk : (bad -> int) -> bad.
```

## Why this is an error

A negative occurrence would allow a non-terminating term without recursion, so inductive families must
occur only strictly positively in the arguments of their constructors.

Families whose constructors refer to each other form a mutual block, and each of them must occur only
strictly positively in the constructors of all of them. Here `close` closes the block of `term` and
`closure`, and takes a function out of `term`:

```hugin fail=E0913 elaborate
empty : Type.
term : Type.
closure : Type.
lam : closure -> term.
close : (term -> empty) -> closure.
```

See [Inductive families](https://k0uks1.github.io/hugin/reference/meta/families.html#strict-positivity).

## How to fix it

Let the family occur only to the right of arrows in the argument types:

```hugin elaborate
good : Type.
mk : (int -> good) -> good.
```
