# E0302: `..` in a head

A rest pattern `..` appears in a rule head.

## Example

```hugin fail=E0302
item : (name : string) -> (price : int) -> rel.
cheap : rel.
item { name = "pen", .. } :- cheap.
```

## Why this is an error

A rule head derives a fact, so every column must be known; `..` would leave the omitted columns
undetermined.

## How to fix it

```hugin
item : (name : string) -> (price : int) -> rel.
cheap : rel.
item { name = "pen", price = 1 } :- cheap.
```
