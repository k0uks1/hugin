# E0002: unterminated comment or string

A `(*` comment or a string literal reaches the end of its file or line.

## Example

```hugin fail=E0002
name : string -> rel.
name "unterminated.
```

## Why this is an error

A string literal ends at the next `"` on the same line, and a comment `(* ... *)` at its matching `*)`
(comments nest). Without the closing delimiter the rest of the line, or of the file, would be swallowed.
An unterminated string ends before a `(*` on its line, so that a stray `"` before a comment does
not turn the comment's text into code.

## How to fix it

Close the string on the same line:

```hugin
name : string -> rel.
name "terminated".
```
