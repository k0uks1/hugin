# E0962: cycle through the program of a file or a module body

A rule, a query or a directive uses a declaration that is about the program it is part of: a
declaration that uses `programOf here`, a judgment `here ⊢ r t̄` or `⊢ r t̄`, or a relation of the file
(or body) written as a proposition, `r t̄` in its type, directly or through other declarations.

## Example

```hugin fail=E0962
%use "std/semantics".
%use "std/quote".
city : type. berlin, paris : city.
road : city -> city -> rel.
road berlin paris.
start : program -> ⇑city.
start P = <berlin>.
fileP : program = programOf here.
fromStart : city -> rel.
fromStart X :- road Y X, Y = $(start fileP).
```

## Why this is an error

`programOf here` is the program of the current file (inside a module body, of that body): its relations
and its rules (see [Order of elaboration](https://k0uks1.github.io/hugin/reference/meta/index.html#order-of-elaboration)).
A declaration that uses it, such as `fileP`, and every declaration that uses one of those, is elaborated
after the file's rules, queries and directives, since it needs all of them. The rule for `fromStart`
splices `fileP`: the rule would be part of the program that `fileP` is computed from, so the program would
depend on itself. The diagnostic names the declarations through which the item reaches the program.

The same holds for a declaration whose type writes a relation of the file as a proposition, such as
`hopped : hop berlin paris -> ⇑city`, which a rule may not splice; for the members of a module body that
use `here`, the program of that body, or its relations as propositions; and for an object constant that
depends on such a declaration: an object constant is part of the program.

## How to fix it

Keep the rules independent of the declarations about the program: state the property separately, or
compute the rule's data from something that does not read the program.

```hugin
%use "std/semantics".
%use "std/quote".
city : type. berlin, paris : city.
road : city -> city -> rel.
road berlin paris.
start : ⇑city = <berlin>.
fileP : program = programOf here.
fromStart : city -> rel.
fromStart X :- road Y X, Y = $start.
%opaque fileP.
```
