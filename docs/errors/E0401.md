# E0401: no value can occur in all these positions

The expected types of a variable have an empty meet.

## Example

```hugin fail=E0401
city : type.
person : type.
lives : person -> city -> rel.
both : rel.
both :- lives X _, lives _ X.
```

## Why this is an error

The type of a variable is the meet (the greatest common subtype) of the types of all the positions it
occurs in. Here `X` is a `person` in one atom and a `city` in the other; no value is both, so the rule
could never fire.

## How to fix it

```hugin
city : type.
person : type.
lives : person -> city -> rel.
both : rel.
both :- lives X _, lives X _.
```
