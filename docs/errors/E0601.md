# E0601: stratification cycle through negation

A cycle of the dependency graph contains a negative edge.

## Example

```hugin fail=E0601
base : int -> rel.
base 1.
p : int -> rel.
q : int -> rel.
p X :- base X, not q X.
q X :- base X, not p X.
```

## Why this is an error

Negation and aggregation need the negated relation to be complete before they are evaluated, so they
must not occur in a recursive cycle: the program is evaluated stratum by stratum. A fact constructor
asserted in the head of another relation's rule depends on what that rule reads, which can close a cycle
too (see `docs/NOTES.md`, "Nested head constructors and the evaluation order").

## How to fix it

```hugin
base : int -> rel.
base 1.
p : int -> rel.
q : int -> rel.
p X :- base X, X > 0.
q X :- base X, not p X.
```
