# E0701: invalid directive

A directive refers to a relation of the wrong kind or arity, or is malformed.

## Example

```hugin fail=E0701
cell : int -> int -> rel.
%terminates (I, I) (cell I _).
```

## Why this is an error

Directives such as `%terminates` and `%derivations` must match the relation they name: labels that
exist, measure variables that occur exactly once, and rule names that exist.

## How to fix it

Use each variable once in the measure:

```hugin
cell : int -> int -> rel.
%terminates (I, J) (cell I J).
```
