# E0903: cannot infer

Elaboration cannot determine a type or an implicit argument.

## Example

```hugin fail=E0903 elaborate
ident = [x] x.
```

## Why this is an error

Types and implicit arguments are inferred by unification. When nothing in the program determines them,
a type annotation is needed.

## How to fix it

Declare the type of the definition:

```hugin elaborate
ident : int -> int = [x] x.
```
