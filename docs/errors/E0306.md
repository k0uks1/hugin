# E0306: unknown label

A named pattern uses a label that the relation does not have.

## Example

```hugin fail=E0306
item : (name : string) -> (price : int) -> rel.
titles : string -> rel.
titles N :- item { title = N, .. }.
```

## Why this is an error

The labels of a named pattern must be column labels of the relation, and a relation used with a named
pattern must label all of its columns.

## How to fix it

```hugin
item : (name : string) -> (price : int) -> rel.
titles : string -> rel.
titles N :- item { name = N, .. }.
```
