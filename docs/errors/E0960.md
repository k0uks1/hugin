# E0960: applied relation used as a meta type

A relation (or struct) that no program owns is applied to arguments where a meta type is expected, such
as the type of a parameter of a meta function; or an applied relation is written under an explicit lift
`⇑(r t̄)`; or such a relation is used unapplied where a family of meta types is expected, which would
apply it.

## Example

```hugin fail=E0960
%use "std/graph".
%use "std/semantics".
edgeIn : {x y : G.node} -> G.edge x y -> tc G ⊢ G.edge x y.
edgeIn E = E.
```

## Why this is an error

A relation used as a type is its fact type, whose values are the identities of its facts (see
[Fact types](https://k0uks1.github.io/hugin/reference/object/types.html#fact-types)): `w : fast.path =
<fast.path berlin paris>.` is such an identity. An applied relation is not an object type, so under `⇑` it
would be the fact type of an application, which no object term has. A theorem stated with it would prove
nothing. The object level rejects the same text in an object type (E0909).

Whether an atom holds is not a property of the relation alone: it depends on the program whose rules
derive it, and on the input facts. That proposition is a judgment (see
[`std/semantics`](https://k0uks1.github.io/hugin/reference/std/semantics.html#the-judgment-notation)).
A relation that a program owns, such as `fast.path` of an instance or `(tc G).path` of a functor
application, is read as that program's judgment where a meta type is expected (see
[Relations as propositions](https://k0uks1.github.io/hugin/reference/std/semantics.html#relations-as-propositions)).
The relation `G.edge` of a variable is owned by no program: `tc G` and `tc2 G` both read it, and the
judgment must say which. A relation of the file, of a module body or of a functor's parameter is read as
a judgment of that file's or body's program only in its own declarations about that program (see
[Inside bodies and files](https://k0uks1.github.io/hugin/reference/std/semantics.html#inside-bodies-and-files)):
a relation of the file inside a module body is owned by no program there. Without `std/semantics`
loaded, no relation is read as a judgment.

## How to fix it

Name the program with the turnstile, `P ⊢ r t̄`:

```hugin
%use "std/graph".
%use "std/semantics".
edgeIn : {x y : G.node} -> tc G ⊢ G.edge x y -> tc G ⊢ G.edge x y.
edgeIn E = E.
```

Under an explicit lift, drop the `⇑`: `fast.path x y` alone is the judgment `fast ⊢ path x y`.
