# E0905: not a function

A term that is not a function is applied to an argument.

## Example

```hugin fail=E0905 new-meta
edge : int -> int -> rel.
p : rel.
p :- edge 1 2 3.
```

## Why this is an error

Only functions (and relations, which are functions into `rel`) take arguments; here `edge 1 2` is already
a complete atom.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
edge : int -> int -> rel.
p : rel.
p :- edge 1 2.
```
