# E0912: possibly non-terminating meta function

A recursive meta function cannot be shown to terminate.

## Example

```hugin fail=E0912 new-meta
nat : Type.
zero : nat.
suc : nat -> nat.
grow : nat -> nat.
grow zero = zero.
grow (suc N) = grow (suc (suc N)).
```

## Why this is an error

Meta functions are total, so compilation always terminates: recursive calls must make an argument
structurally smaller (size-change termination), for example `N` from `suc N`.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
nat : Type.
zero : nat.
suc : nat -> nat.
shrink : nat -> nat.
shrink zero = zero.
shrink (suc N) = shrink N.
```
