# E0501: unbound variable

A rule is not range-restricted: a variable is not bound by the body in the canonical order.

## Example

```hugin fail=E0501
edge : int -> int -> rel.
free : int -> int -> rel.
free X Y :- edge X _.
```

## Why this is an error

Rules are evaluated bottom-up, so every variable of the head, and every variable of a comparison,
arithmetic, negation or aggregate in the body, must be bound by a positive relation atom or an equation
whose other side is bound. The body is reordered into a canonical order in which this holds, if one
exists.

## How to fix it

```hugin
edge : int -> int -> rel.
free : int -> int -> rel.
free X Y :- edge X Y.
```
