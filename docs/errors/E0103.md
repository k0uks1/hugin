# E0103: misclassified item

The item cannot be classified by stage.

## Example

```hugin fail=E0103
f : int -> type.
```

## Why this is an error

Every declaration is classified by its type: an object type, a constructor, a relation, a formula
function, a type definition or a meta definition. The following declarations have no classification:

* a function that returns `type`; declare a family with type parameters instead;
* a relation defined by `=`; relations are defined by rules;
* a signature without a definition;
* an unknown base type in `%builtin`;
* a primitive operation, such as `%builtin same`, declared with another type than its own;
* a constructor whose result is not an open type, such as a refinement `a : type <: b.` or the fact type
  of a struct or relation: `c : int -> s.` for `s : type = { x : int }.` is rejected, since the values
  of `s` are the facts of `s`.

## How to fix it

Declare a family of object types, with a type parameter:

```hugin
f A : type.
```
