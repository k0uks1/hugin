An applied relation of a program, written where a type is expected, is that program's judgment: (undirected G).reach x y means undirected G ⊢ reach x y. Written without arguments, (undirected G).reach is the family [x] [y] undirected G ⊢ reach x y. So a property of meta relations, such as symmetric here, applies to an object relation as it is.

Symmetry of reach needs two lemmas. linkSym: each rule of link derives the reverse of the other's head, from the same edge. reachTrans: transitivity, as in the previous lesson. Then reachSym is by induction: a one-step path is reversed by linkSym; a path link x Y, reach Y z is reversed by reversing the rest (the recursive call) and appending the reversed link with reachTrans.
