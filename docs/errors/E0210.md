# E0210: negation over a parameter without %complete

A functor that negates or aggregates over a relation parameter does not require `%complete` in its
signature.

## Example

```hugin fail=E0210
any_graph : Type = { node : type, edge : node -> node -> rel }.
sinks (g : any_graph) = {
  sink : g.node -> rel.
  sink N :- g.edge _ N, not g.edge N _.
}.
city : type.
road : city -> city -> rel.
s = sinks { node = city, edge = road }.
```

## Why this is an error

Negation and aggregation are only meaningful over complete relations. A functor does not know which
relation it will be applied to, so its signature must require completeness; every application is then
checked (E0208).

## How to fix it

Require `%complete edge` in the signature:

```hugin
complete_graph : Type = { node : type, edge : node -> node -> rel, %complete edge }.
sinks (g : complete_graph) = {
  sink : g.node -> rel.
  sink N :- g.edge _ N, not g.edge N _.
}.
city : type.
road : city -> city -> rel.
s = sinks { node = city, edge = road }.
```
