# E0911: non-covering clauses

The clauses of a meta function do not cover every case.

## Example

```hugin fail=E0911 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
pred : nat -> nat.
pred (suc N) = N.
```

## Why this is an error

Meta functions are total: every argument must match some clause, so that compile-time evaluation never
gets stuck. The missing patterns are listed; cases that are impossible by typing need no clause.

## How to fix it

```hugin elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
pred : nat -> nat.
pred zero = zero.
pred (suc N) = N.
```
