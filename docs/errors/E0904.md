# E0904: universe inconsistency

A type is used as an element of itself.

## Example

```hugin fail=E0904 new-meta
u : Type = Type.
bad : u = u.
```

## Why this is an error

`Type : Type` would make the meta level inconsistent (Girard's paradox), so `Type` lives in a higher
universe than the types it contains.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
u : Type = int.
ok : u = 1.
```
