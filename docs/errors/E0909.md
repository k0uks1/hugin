# E0909: staging failure

Meta code spliced into an object item does not compute to object code.

## Example

```hugin fail=E0909 elaborate
f : int -> int.
q : int -> rel.
q (f 1).
```

## Why this is an error

Object items are staged by evaluating the meta code they splice. What remains must be pure object code;
a function without a definition, for example, leaves a stuck application.

## How to fix it

```hugin elaborate
f : int -> int = [x] x + 1.
q : int -> rel.
q (f 1).
```
