# E0104: cyclic type definition

Type definitions refer to each other in a cycle.

## Example

```hugin fail=E0104
a : type = b.
b : type = a.
```

## Why this is an error

Type definitions may be used before they are declared, but expanding them must terminate: a type
definition stands for its right-hand side, so a cycle would stand for an infinite type. Recursive data
is declared with an object type and constructors instead.

## How to fix it

Break the cycle:

```hugin
a : type = int.
b : type = a.
```
