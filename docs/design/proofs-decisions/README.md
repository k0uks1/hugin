# #186 implementation decisions

The record of every decision made while implementing issue #186 (proofs about Datalog programs), levels 3
and 3.5, kept for the designer to review again.

- `log.md`: the raw decisions log. It has the lead decisions (L1–L33) and each batch's implementation
  decisions (P1–P9g).
- `index.html`: the same content as a readable page. It adds a summary, the flagged deviations from the approved
  designs (`../proofs.md`, `../proofs-level35.md`) and the open gaps. Open it in a browser.
