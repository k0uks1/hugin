# E0207: arity mismatch

A relation, constructor, family or formula function is applied to the wrong number of arguments.

## Example

```hugin fail=E0207
graph : mod = { node : type, edge : node -> node -> rel }.
tc (g : graph) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
  path X Z :- g.edge X Y, path Y Z.
}.
city : type.
road : city -> city -> rel.
weight : city -> city -> int -> rel.
bad = tc { node = city, edge = road } 5.
```

## Why this is an error

Every relation, constructor, family, functor and formula function has a fixed number of parameters,
and each use must supply exactly that many arguments.

## How to fix it

```hugin
graph : mod = { node : type, edge : node -> node -> rel }.
tc (g : graph) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
  path X Z :- g.edge X Y, path Y Z.
}.
city : type.
road : city -> city -> rel.
weight : city -> city -> int -> rel.
ok = tc { node = city, edge = road }.
```
