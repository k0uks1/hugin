# E0955: `--certify` without its library

`hugin run --certify` checks the run with the checker of
[`std/certify`](https://k0uks1.github.io/hugin/reference/std/certify.html), and the program does not load
that library.

## Example

```hugin fail=E0955 certify
edge : int -> int -> rel.
edge 1 2.
edge 2 3.
path : int -> int -> rel.
path X Y :- edge X Y.
path X Z :- edge X Y, path Y Z.
```

## Why this is an error

The checker of a certified run is meta code: functions of `std/certify` whose correctness is proved in
Hugin against the semantics of `std/semantics` and `std/strata`. It is elaborated with the program, so
that the run's facts and derivations can be given to it as meta data after the run. A program that
does not load `std/certify` has no checker to run.

## How to fix it

Load the library:

```hugin certify
%use "std/certify".
edge : int -> int -> rel.
edge 1 2.
edge 2 3.
path : int -> int -> rel.
path X Y :- edge X Y.
path X Z :- edge X Y, path Y Z.
```
