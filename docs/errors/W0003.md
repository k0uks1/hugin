# W0003: unused definition

A top-level meta function, formula function or constant is never referenced.

## Example

```hugin fail=W0003
limit : int = 10.
p : int -> rel.
p 1.
```

## Why this is reported

Unused definitions are usually leftovers. Lint name: `unused_definitions`.

## How to fix it

```hugin
limit : int = 10.
p : int -> rel.
p limit.
```
