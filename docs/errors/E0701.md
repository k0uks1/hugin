# E0701: invalid directive

A directive refers to a relation of the wrong kind or arity, or is malformed.

## Example

```hugin fail=E0701
p : int -> int -> rel.
%terminates (X, X) (p X _).
```

## Why this is an error

Directives such as `%mode`, `%terminates` and `%derivations` must match the relation they name: one mode
item per column, labels that exist, measure variables that occur exactly once, and rule names that
exist.

## How to fix it

```hugin
p : int -> int -> rel.
%terminates (X, Y) (p X Y).
```
