# W0006: unreachable clause

A clause of a meta function is never used.

## Example

```hugin fail=W0006 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
isZero : nat -> int.
isZero zero = 1.
isZero N = 0.
isZero (suc N) = 0.
```

## Why this is reported

The clauses before it cover every case it matches, so it can be removed. Lint name:
`unreachable_clauses`. An unreachable clause is still checked in its own context, so its errors are
reported. A clause that matches no argument at all, because its own constructors cannot occur, is an
error instead ([E0915](E0915.md)); an absurd clause `f ().` is never unreachable.

## How to fix it

Remove the unreachable clause:

```hugin elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
isZero : nat -> int.
isZero zero = 1.
isZero (suc N) = 0.
```
