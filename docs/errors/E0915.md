# E0915: invalid pattern

A clause or pattern is malformed, or matching on it cannot be decided.

## Example

```hugin fail=E0915 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
same : nat -> nat -> nat.
same N N = N.
```

## Why this is an error

Patterns are linear (each variable is bound once) and consist of constructors and variables; all clauses
of a function have the same number of patterns. Matching must be decidable by unification: an index that
is a stuck function application cannot be matched on.

Each clause is checked in its own context, the arguments split by its patterns alone: a constructor
pattern that cannot occur there (its indices conflict with those of the argument's type) is an error, as
the clause can never apply. An absurd pattern `()` is allowed only in the patterns of a clause without
right-hand side (`r ().`), and only at a position none of whose constructors can occur.

```hugin fail=E0915 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
bool : Type.
true : bool.
vec : Type -> nat -> Type.
vnil : vec A zero.
vcons : A -> vec A N -> vec A (suc N).
k : (n : nat) -> vec bool n -> nat.
k zero (vcons X XS) = zero.
k _ _ = zero.
```

```hugin fail=E0915 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
r : nat -> nat.
r ().
```

A function needs a declaration with its type before it can have clauses. The clauses of a module body
belong to the functions that the body declares: a clause in a body for a function declared only outside
it has no declaration.

```hugin fail=E0915 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
double : nat -> nat.
double zero = zero.
double (suc N) = suc (suc (double N)).
m = {
  double zero = zero.
}.
```

## How to fix it

Use distinct variables in the patterns:

```hugin elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
first : nat -> nat -> nat.
first N M = N.
```

Remove a clause that can never apply (`hugin fix` does). For a function on an empty type, write an absurd
clause:

```hugin elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
fin : nat -> Type.
fzero : fin (suc N).
fsuc : fin N -> fin (suc N).
r : fin zero -> nat.
r ().
```

Declare the function in the body whose clauses define it:

```hugin elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
m = {
  double : nat -> nat.
  double zero = zero.
  double (suc N) = suc (suc (double N)).
}.
```
