# E0001: syntax error

The parser found a token it did not expect.

## Example

```hugin fail=E0001
edge : int -> int -> rel
path : int -> int -> rel.
```

## Why this is an error

Every item (declaration, definition, rule, query or directive) ends with a period. When the parser meets
a token that cannot continue the current item, it reports this error, skips to the next period and
resumes there, so that one mistake does not hide the errors after it.

## How to fix it

```hugin
edge : int -> int -> rel.
path : int -> int -> rel.
```

## Related

E0002 (unterminated comment or string), E0004 (malformed item).
