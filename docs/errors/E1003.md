# E1003: directive changed the declaration it is attached to

A directive written before a declaration returned the declaration of another object constant.

## Example

```hugin fail=E1003
%use "std/reflect".
node : type.
edge : node -> node -> rel.
redirect : decl -> decl.
redirect D = output '( edge ).
%redirect
other : node -> rel.
```

## Why this is an error

A directive of type `decl -> decl` is *local* (see
[Directives](https://k0uks1.github.io/hugin/reference/directives.html)): it changes the declaration it is attached
to, and nothing else. This is what lets the compiler elaborate every other item without regard to it. A
directive that changes another declaration would have to be applied to that one.

## How to fix it

Return the declaration the directive is given, or apply the directive to the declaration it changes:

```hugin
%use "std/reflect".
node : type.
edge : node -> node -> rel.
make_output : decl -> decl.
make_output D = output D.
%make_output
other : node -> rel.
%output edge.
```
