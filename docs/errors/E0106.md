# E0106: non-strict type definition

A type definition does not mention every parameter on its right-hand side.

## Example

```hugin fail=E0106
first A B : type = A.
```

## Why this is an error

A type definition with a parameter its right-hand side ignores is not strict: the parameter could not
be inferred from the expanded type. Mark the definition `%abbrev` to have it always expanded, as an
abbreviation, or remove the parameter.

## How to fix it

```hugin
%abbrev first A B : type = A.
```
