# E0301: missing labels in named pattern

A named pattern does not mention every label of the relation.

## Example

```hugin fail=E0301
item : (name : string) -> (price : int) -> rel.
names : string -> rel.
names N :- item { name = N }.
```

## Why this is an error

A named pattern `r { l = t, ... }` stands for an atom with one argument per column, so every label must
be given, unless the pattern ends in `..`, which leaves the omitted columns unconstrained.

## How to fix it

End the pattern with `..` to leave the other columns unconstrained:

```hugin
item : (name : string) -> (price : int) -> rel.
names : string -> rel.
names N :- item { name = N, .. }.
```
