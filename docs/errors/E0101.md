# E0101: unresolved name

A name is not declared in any enclosing scope.

## Example

```hugin fail=E0101
road : int -> int -> rel.
path : int -> int -> rel.
path X Y :- raod X Y.
```

## Why this is an error

Names are resolved in the enclosing module bodies, from the innermost outwards, then in the names the
file opens with `%use`, and then in the prelude. A name that none of them declares is an error. When a
declaration with a similar name exists, it is suggested; the suggestion is a guess, so editors offer it
but do not apply it on their own. A path `m.x` whose module `m` has no member `x` is reported with this
code too.

## How to fix it

Correct the spelling of the name:

```hugin
road : int -> int -> rel.
path : int -> int -> rel.
path X Y :- road X Y.
```
