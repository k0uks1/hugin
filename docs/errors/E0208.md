# E0208: unsatisfied requirement

A relation passed to a functor does not satisfy `%complete` or `%mode` required by the signature.

## Example

```hugin fail=E0208
g : mod = { node : type, edge : node -> node -> rel, %complete edge }.
iso (x : g) = {
  lonely : x.node -> rel.
  lonely N :- x.edge N _, not x.edge _ N.
}.
v : type.
e : v -> v -> rel.
%open e.
a = iso { node = v, edge = e }.
```

## Why this is an error

A signature can require that a relation field is complete (`%complete edge`), because the functor
negates or aggregates over it, or that it has a mode (`%mode edge + -`), because the functor calls it
with that binding pattern. The relation passed must satisfy the requirement: an `%open` or `%partial`
relation is not complete, and a mode must be declared.

## How to fix it

```hugin
g : mod = { node : type, edge : node -> node -> rel, %complete edge }.
iso (x : g) = {
  lonely : x.node -> rel.
  lonely N :- x.edge N _, not x.edge _ N.
}.
v : type.
e : v -> v -> rel.
a = iso { node = v, edge = e }.
```
