# W0001: undefined constant expression

An object-level expression over literals is undefined, so the rule can never fire.

## Example

```hugin fail=W0001
ratio : int -> rel.
ratio X :- X = 1 / 0.
```

## Why this is reported

Arithmetic over literals is folded at compile time. When the result is undefined (overflow or division
by zero), the formula containing it never holds, so the rule instance never fires; that is allowed but
almost certainly a mistake. Lint name: `undefined_constant_expressions`.

## How to fix it

Divide by a literal other than zero:

```hugin
ratio : int -> rel.
ratio X :- X = 1 / 1.
```
