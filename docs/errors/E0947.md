# E0947: judgment whose database is not determined

A judgment `P ⊢ r t̄` without a database `[e]` is outside the type of a declaration, and elaboration did
not determine its database.

## Example

```hugin fail=E0947
%use "std/graph".
%use "std/semantics".
pathOf (g : graph) (d : db) (x : g.node) (y : g.node) : Type = tc g ⊢ path x y.
```

## Why this is an error

A judgment is about the facts a program derives from a database of input facts (see
[`std/semantics`](https://k0uks1.github.io/hugin/reference/std/semantics.html#generalisation)). In the
type of a declaration, the judgments without `[e]` share the declaration's one anonymous database, an
implicit argument. Elsewhere, such as in the definition of `pathOf`, a judgment without `[e]` has an
unknown database, which must follow from the expected type, as for an implicit argument. Nothing
determines it here: the parameter `d` is not used, since no name has a meaning for a judgment that the
judgment does not write.

## How to fix it

Give the database:

```hugin
%use "std/graph".
%use "std/semantics".
pathOf (g : graph) (d : db) (x : g.node) (y : g.node) : Type = tc g ⊢[d] path x y.
```
