# E0307: duplicate label

A label occurs twice in a record, record type, signature or named pattern, or names two columns of a
relation or constructor declaration (`r : (a : int) -> (a : int) -> rel.`).

## Example

```hugin fail=E0307
rec = { n = 1, n = 2 }.
```

## Why this is an error

Labels name the fields of a record or the columns of a relation, so each may occur only once.

## How to fix it

```hugin
rec = { n = 1, m = 2 }.
```
