# E0210: negation over a parameter without %complete

A functor that negates or aggregates over a relation parameter does not require `%complete` in its signature.

## Example

```hugin fail=E0210
g : Type = { node : type, edge : node -> node -> rel }.
sinks (x : g) = {
  sink : x.node -> rel.
  sink N :- x.edge _ N, not x.edge N _.
}.
v : type.
e : v -> v -> rel.
s = sinks { node = v, edge = e }.
```

## Why this is an error

Negation and aggregation are only meaningful over complete relations. A functor does not know which
relation it will be applied to, so its signature must require completeness; every application is then
checked (E0208).

## How to fix it

```hugin
g : Type = { node : type, edge : node -> node -> rel, %complete edge }.
sinks (x : g) = {
  sink : x.node -> rel.
  sink N :- x.edge _ N, not x.edge N _.
}.
v : type.
e : v -> v -> rel.
s = sinks { node = v, edge = e }.
```

## Related

E0208 (unsatisfied requirement), E0602 (negation over an incomplete relation).
