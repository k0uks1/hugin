# E0929: equality library not loaded

`match H : e with …` and `rewrite h in e` use the equality of the bundled library `std/eq`, which the
program does not load.

## Example

```hugin fail=E0929
flip : bool -> bool.
flip B = match H : B with
  | true => false
  | false => true.
```

## Why this is an error

The equation that `match H : e` binds in each branch is `eq e p` of `std/eq`, and `rewrite h in e`
elaborates to `subst P (sym h) e` with `subst` and `sym` of `std/eq` (see
[`match` and `rewrite`](https://k0uks1.github.io/hugin/reference/meta/match.html)). Like Agda's
`BUILTIN EQUALITY`, the family is the library's, so a program that uses them loads the library.

## How to fix it

Load `std/eq` with `%use`, or leave out the equation if it is not needed:

```hugin
%use "std/eq".
flip : bool -> bool.
flip B = match H : B with
  | true => false
  | false => true.
```
