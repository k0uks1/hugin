tc2 computes the same closure with the doubling rule path X Z :- path X Y, path Y Z, which needs logarithmically many rounds of evaluation where tc needs linearly many. The theorem sameFacts says the rewrite is correct: for every graph and every input, both programs derive the same paths.

The proof is in two directions. toTc2 maps each rule of tc to rules of tc2. toTc maps the doubling rule to tcTrans, the transitivity of tc from the earlier lesson: that is where the induction is needed. edgeIn and edgeOut move an input edge between the two programs, which read the same parameter relation.

The lemmas are written inside the functor's body. There, path x y unqualified is the judgment of the body's own program, tc2 g ⊢ path x y, and the other program is qualified, (tc g).path x y. Members of a body are fields of every instance: fast.sameFacts is the theorem about the instance fast, without restating it.

What is proved. For every graph and every input database, tc and tc2 derive the same facts path x y; so does fast with tc over the same roads. What is trusted. Adequacy: that the engine's runs of both programs print the derived facts. Running time is not part of the statement.
