# E0912: possibly non-terminating meta function

A recursive meta function cannot be shown to terminate.

## Example

```hugin fail=E0912 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
grow : nat -> nat.
grow zero = zero.
grow (suc N) = grow (suc (suc N)).
```

## Why this is an error

Meta functions are total, so compilation always terminates: recursive calls must make an argument
structurally smaller (size-change termination), for example `N` from `suc N`.

The calls of a clause are taken in its own context, with its patterns as written: the clauses before
it do not refine them. In `h zero _ = zero. h N M = h (predf N) M.` the call `h (predf N) M` does not
decrease, although `N` is `suc _` whenever the second clause is used. The error then has a fix that
writes out those cases, `h (suc N1) M = h (predf (suc N1)) M.`, in which the call decreases.

## How to fix it

Recurse on a smaller argument:

```hugin elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
shrink : nat -> nat.
shrink zero = zero.
shrink (suc N) = shrink N.
```
