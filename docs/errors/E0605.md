# E0605: invalid bound column

A bound column type `min τ` or `max τ` is used where it is not allowed.

## Example

```hugin fail=E0605
node : type.
first : (d : min int) -> (v : node) -> rel.
```

## Why this is an error

A bound column keeps only the best value (the least for `min`, the greatest for `max`) per key, the key
being the other columns. So it must be the last column of a relation declaration (not of a constructor,
a struct or a signature field), of an integer type, and the relation must not have a `%mode`: demand
would read partial best values. See `docs/REDESIGN.md`, "Bound columns".

## How to fix it

```hugin
node : type.
first : (v : node) -> (d : min int) -> rel.
```
