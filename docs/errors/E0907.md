# E0907: not supported by the meta level

The program uses a construct that the meta level does not support (yet).

## Example

```hugin fail=E0907 elaborate
m = { small : type <: int. }.
```

## Why this is an error

Some constructs of the redesign are not implemented: refinements and families of object types in
module bodies, among others. The open issues are listed in docs/NOTES.md.

## How to fix it

Declare the construct at the top level of a file:

```hugin elaborate
small : type <: int.
```
