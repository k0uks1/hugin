Install Hugin

Hugin is built from source with sbt and runs on the JVM. The build produces the hugin command: the compiler, a REPL and a language server. To try Hugin without installing anything, use the playground.

  1. Step one

    Install a JDK and sbt

    Hugin needs a JDK, version 17 or later, and sbt 1.10 or later. Check both:

    java -version
sbt --version

  2. Step two

    Build Hugin

    Clone the repository and stage the launcher. The first build downloads the dependencies and takes a few minutes.

    git clone https://github.com/k0uks1/hugin
cd hugin
sbt stage

    The launcher is target/universal/stage/bin/hugin. The wrapper bin/hugin in the checkout calls it, and stages it first if needed; put bin/ on your PATH to call it as hugin.

  3. Step three

    Run a program

    hugin run compiles a program, evaluates it and prints the answers to its queries and its %output relations. hugin check only compiles it and reports the diagnostics.

    hugin run examples/graphs.hgn
hugin check examples/typechecker.hgn
hugin explain E0603       # explain a diagnostic code
hugin --help              # all commands and options

    hugin repl starts an interactive session: declarations and rules extend the session, queries are answered at once, and :help lists the commands.

    hugin repl examples/graphs.hgn

  4. Step four

    Set up an editor

    The VS Code extension in editors/vscode highlights Hugin and runs the language server (hugin lsp): diagnostics, hover, go to definition, completion and quick fixes. CI packages it on every push: download the artifact hugin-vscode of a recent CI run and install it, or build it yourself:

    cd editors/vscode
npm install
npm run package
code --install-extension hugin-*.vsix

    The extension starts hugin from the PATH; otherwise set hugin.server.path to bin/hugin in the checkout. Other editors can use the same language server for files ending in .hgn and .facts.
