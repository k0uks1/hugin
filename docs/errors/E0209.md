# E0209: compile-time arithmetic failure

A primitive operation evaluated at the meta level is undefined (overflow or division by zero).

## Example

```hugin fail=E0209
big : int = 9223372036854775807.
next : int = big + 1.
r : int -> rel.
r next.
```

## Why this is an error

Meta definitions are evaluated by the compiler. An undefined operation there has no value to continue
with, so it is a compile-time error; the same operation in a rule makes only that rule instance fail
(see W0001).

## How to fix it

```hugin
big : int = 9223372036854775807.
next : int = big - 1.
r : int -> rel.
r next.
```
