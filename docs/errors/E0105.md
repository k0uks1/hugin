# E0105: self-referential definition

A meta definition refers to itself.

## Example

```hugin fail=E0105
self : int = self + 1.
```

## Why this is an error

A definition `x : A = e.` is a value: `x` is not in scope in `e`, since a value defined by itself has
no meaning at compile time. Definitions may refer to each other in any order, as long as they do not
form a cycle. A recursive meta function is declared with its type and defined by clauses, which the
compiler checks for termination.

## How to fix it

Define the value without referring to it:

```hugin
one : int = 1.
two : int = one + 1.
```
