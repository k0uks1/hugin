# E0913: non-positive occurrence

An inductive family occurs to the left of an arrow in one of its constructors.

## Example

```hugin fail=E0913 new-meta
bad : Type.
mk : (bad -> int) -> bad.
```

## Why this is an error

A negative occurrence would allow a non-terminating term without recursion, so inductive families must
occur only strictly positively in the arguments of their constructors.
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
good : Type.
mk : (int -> good) -> good.
```
