# E0905: not a function

A term that is not a function is applied to an argument.

## Example

```hugin fail=E0905 new-meta
limit : int = 3.
twice = limit 2.
```

## Why this is an error

Only functions take arguments; here `limit` is a compile-time integer. (A relation applied to too many
arguments is reported as E0207.)
This code is reported by the new meta level (`hugin check --new-meta`, redesign Phase B), which is not yet
the default front end.

## How to fix it

```hugin new-meta
limit : int = 3.
twice = limit * 2.
```
