# E0103: misclassified item

The item cannot be classified by stage.

## Example

```hugin fail=E0103
f : int -> type.
```

## Why this is an error

Every declaration is classified by its type: an object type, a constructor, a relation, a formula
function, a type definition or a meta definition. Some combinations have no stage: a function returning
`type` (use a family with type parameters), a relation defined by `=` (relations are defined by rules), a
signature without a definition, `%fact` on something that is not a constructor, or an unknown base type
in `%builtin`.

## How to fix it

```hugin
f A : type.
```
