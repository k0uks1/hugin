# E0921: shared type not used at its parameters

A constructor of a shared data type `T ā` returns `T` at other arguments than its parameters (an
index), or uses `T` at other arguments in one of its arguments (polymorphic recursion); or a parameter
of the declaration is not a plain variable.

## Example

```hugin fail=E0921
tree A : data.
leaf : A -> tree A.
node : tree (list A) -> tree A.
```

## Why this is an error

A shared type is a family of polynomial types in its parameters: every constructor returns `T ā` and uses
`T` only at `ā`. The object side of the declaration is a family of object constants, which the object
level instantiates once per closed argument (`tree[int]`). An index has no object counterpart, and
polymorphic recursion would need infinitely many instances (E0205 at the object level). Meta inductive
families allow both; shared ones do not. See [Inductive
families](https://k0uks1.github.io/hugin/reference/meta/families.html#shared-data).

## How to fix it

Use the type at its parameters; a different structure goes into an auxiliary shared type:

```hugin
tree A : data.
leaf : A -> tree A.
node : list (tree A) -> tree A.
```
