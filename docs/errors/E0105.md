# E0105: self-referential definition

A meta definition, or a formula function, refers to itself.

## Example

```hugin fail=E0105
self : int = self + 1.
```

## Why this is an error

A definition `x : A = e.` is a value: `x` is not in scope in `e`, since a value defined by itself has
no meaning at compile time. Definitions may refer to each other in any order, as long as they do not
form a cycle. A recursive meta function is declared with its type and defined by clauses, which the
compiler checks for termination. The same holds for the definitions of a module body:

```hugin fail=E0105
m = { loop : int -> int = [n] loop n. }.
```

A [formula function](https://k0uks1.github.io/hugin/meta/staging.html#formula-functions)
cannot refer to itself either, directly or through other formula functions, definitions or functions:
its uses are replaced by its formula, so the replacement would never end. The error is reported once for
each such cycle, at the reference in the clauses of its first formula function:

```hugin fail=E0105
node : type.
edge : node -> node -> rel.
linked : node -> node -> prop.
linked X Z :- edge X Y, linked Y Z.
```

## How to fix it

Define the value without referring to it:

```hugin
one : int = 1.
two : int = one + 1.
```

A recursive function, also in a module body, is declared and defined by clauses:

```hugin
nat : Type. zero : nat. suc : nat -> nat.
m = {
  size : nat -> int.
  size zero = 0.
  size (suc N) = 1 + size N.
}.
```

A recursive formula is written with a relation, whose rules may refer to it:

```hugin
node : type.
edge : node -> node -> rel.
linked : node -> node -> rel.
linked X Y :- edge X Y.
linked X Z :- edge X Y, linked Y Z.
```
