# E0109: ambiguous name

A name that two `%use` items open for different declarations is used.

## Example

```hugin fail=E0109
metric = { unit : string = "km". factor : int = 1000. }.
imperial = { unit : string = "mi". factor : int = 1609. }.
%use metric.
%use imperial.
distance : int -> rel.
distance (12 * factor).
```

## Why this is an error

`%use m.` opens the fields of `m` as names of the file. When two opened modules have a field of the same
name that denotes different declarations, a use of the name could mean either, so it is rejected. Opening
the same declaration twice is not an error, and a declaration of the file shadows opened names. Here
`metric` and `imperial` both have a field `factor`. See
[Modules](https://k0uks1.github.io/hugin/modules.html#opening-modules).

## How to fix it

Open only the fields that are needed from one of the modules, with a list of names:

```hugin
metric = { unit : string = "km". factor : int = 1000. }.
imperial = { unit : string = "mi". factor : int = 1609. }.
%use metric.
%use imperial (unit).
distance : int -> rel.
distance (12 * factor).
```
