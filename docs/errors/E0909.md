# E0909: staging failure

Meta code spliced into an object item does not compute to object code.

## Example

```hugin fail=E0909 elaborate
rate : int -> int.
price : int -> rel.
price (rate 1).
```

## Why this is an error

Object items are staged by evaluating the meta code they splice. What remains must be object code.
Here `rate` is a postulate, a function without a definition, so `rate 1` is a stuck application.

## How to fix it

Define the function:

```hugin elaborate
rate : int -> int = [x] x + 1.
price : int -> rel.
price (rate 1).
```
