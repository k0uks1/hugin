# E0701: invalid directive

A directive refers to a constant of the wrong kind or arity, or is malformed.

## Example

```hugin fail=E0701
cell : int -> int -> rel.
%terminates (I, I) (cell I _).
```

## Why this is an error

Directives such as `%terminates` and `%derivations` must match the relation they name: labels that exist,
measure variables that occur exactly once, and rule names that exist. `%opaque` names meta definitions
and functions defined by clauses of the file, not object constants, constructors or names of other files.
See [Opaque definitions](https://k0uks1.github.io/hugin/reference/meta/index.html#opaque-definitions).

```hugin fail=E0701
city : type.
road : city -> city -> rel.
%opaque road.
```

## How to fix it

Use each variable once in the measure:

```hugin
cell : int -> int -> rel.
%terminates (I, J) (cell I J).
```

Make a definition opaque, not a relation:

```hugin
city : type.
road : city -> city -> rel.
limit : int = 3.
%opaque limit.
```
