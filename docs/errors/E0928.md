# E0928: meta integers not available

A compilation without the prelude uses a meta integer.

## Example

```hugin fail=E0928 no-prelude
int : type = %builtin int.
limit : int = 3.
```

## Why this is an error

The meta `int` is the inductive family `int` of `std/nat`, with the constructors `ofNat` and `negSucc`,
and its arithmetic is defined in `std/int`
([`std/int`](https://k0uks1.github.io/hugin/reference/std/int.html)). The prelude imports both, so a
program compiled with `--no-prelude` has no meta integers. Object integers do not need them.

## How to fix it

Compile the program with the prelude, or use object integers only:

```hugin
limit : int = 3.
```

## Related

E0917 (invalid quoted syntax): the reflective types are not part of a compilation without the prelude
either.
