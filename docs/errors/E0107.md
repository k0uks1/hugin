# E0107: not a module

A path `m.x` is used where `m` is not module-valued.

## Example

```hugin fail=E0107
limit = 3.
x = limit.lo.
```

## Why this is an error

Only modules (module bodies, imported files and functor applications) have members. Selecting a member
of a value of another meta type is an error.

## How to fix it

```hugin
bounds = { lo = 0, hi = 3 }.
x = bounds.lo.
```
