# E0205: polymorphic recursion

Within a recursive component, a family is used at type arguments different from those being instantiated.

## Example

```hugin fail=E0205
box A : type.
put : A -> box A.
start : int -> rel.
start 1.
nest : A -> rel.
nest X :- start X.
nest X :- nest (put X).
?- nest 1.
```

## Why this is an error

Families of relations are instantiated at concrete types before evaluation (monomorphization). Inside
a recursive component every relation must be used at exactly the type parameters of the instance being
built; otherwise the instantiation would produce infinitely many instances (`nest[int]`,
`nest[box int]`, ...).

## How to fix it

```hugin
box A : type.
put : A -> box A.
start : int -> rel.
start 1.
nest : A -> rel.
nest X :- start X.
boxed : box A -> rel.
boxed (put X) :- nest X.
?- nest 1.
```
