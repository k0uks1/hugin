# E0907: not supported by the meta level

The program uses a construct that the meta level does not support where it is written.

## Example

```hugin fail=E0907 elaborate
m = { small : type <: int. }.
```

## Why this is an error

Some constructs are not supported in a module body: refinements, families of object constants, meta
inductive families, meta declarations without a definition or clauses (postulates), reflected items
`$e.`, `%use`, and additive or module-wide directives. They are allowed
at the top level of a file. The message names the construct. A member that is rejected is left out, and
its uses in the body are not reported again. See
[Modules](https://k0uks1.github.io/hugin/reference/modules.html#module-bodies).

A meta function defined by clauses is supported in a module body: its declaration and its clauses are
both items of the body. So is a formula function defined by rules.

```hugin fail=E0907 elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
m = {
  pred : nat -> nat.
}.
```

Here `pred` has no clauses in the body, so it is a postulate.

## How to fix it

Declare the construct at the top level of a file:

```hugin elaborate
small : type <: int.
```

Give a meta function its clauses in the body that declares it:

```hugin elaborate
nat : Type.
zero : nat.
suc : nat -> nat.
m = {
  pred : nat -> nat.
  pred zero = zero.
  pred (suc N) = N.
}.
```
