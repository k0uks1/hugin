# E0108: import error

An imported file does not exist, or files import each other in a cycle.

## Example

```hugin fail=E0108
lib = %import "missing".
```

## Why this is an error

A file is a module body that is elaborated before the files importing it, so imports must name existing
files and form an acyclic graph. Paths are resolved relative to the importing file.

## How to fix it

Import a file that exists, or define the module in the program:

```hugin
lib = { size : int = 1. }.
```
