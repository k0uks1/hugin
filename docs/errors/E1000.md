# E1000: error reported by a directive

A directive rejected its arguments: its result contains an error, `derror "…"` (for a directive that
returns a declaration) or `ierror "…"` (for one that returns items). The message is the directive's own.

## Example

```hugin fail=E1000
node : type.
edge : node -> node -> rel.
relations_only : decl -> decl.
relations_only (dconst S As) = dconst S As.
relations_only D = derror "`%relations_only` applies to relations only".
%relations_only @step.
```

## Why this is an error

Directives are meta functions (docs/REDESIGN.md §7): the compiler elaborates `%d a₁ … aₙ.` as the
application `d a₁ … aₙ` and uses its value. A directive checks its arguments with the full power of the
meta level (pattern matching on declarations and object syntax), and where they do not fit it returns
an error instead of a result. The error is reported at the directive, with the directive's message.

## How to fix it

Read the directive's message, and pass it arguments it accepts:

```hugin
node : type.
edge : node -> node -> rel.
relations_only : decl -> decl.
relations_only (dconst S As) = dconst S As.
relations_only D = derror "`%relations_only` applies to relations only".
%relations_only edge.
```
