# E0102: duplicate declaration

A name is declared twice in the same scope.

## Example

```hugin fail=E0102
path : int -> int -> rel.
path : int -> rel.
```

## Why this is an error

Each scope (the top level of a file, or a module body) maps a name to one declaration, so a second
declaration of the same name is rejected. An inner scope may shadow a name of an outer one.

## How to fix it

Give the second relation a name of its own:

```hugin
path : int -> int -> rel.
reachable : int -> rel.
```
