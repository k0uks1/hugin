# E0110: misplaced `%export`

A file has more than one `%export`, or a module body has one.

## Example

```hugin fail=E0110
%export { width : int }.
%export { height : int }.
width : int = 3.
height : int = 4.
size : int -> rel.
size (width * height).
```

## Why this is an error

`%export S.` states the signature of a file: an import of the file has exactly the fields of `S`. A file
has one module, so it has at most one export signature. A module body is given a signature where it is
defined, by an ascription `m : S = { … }.`, not by `%export`. Here the file states two signatures. See
[Modules](https://k0uks1.github.io/hugin/reference/modules.html#export-signatures).

## How to fix it

Put the fields of both signatures into one `%export`:

```hugin
%export { width : int, height : int }.
width : int = 3.
height : int = 4.
size : int -> rel.
size (width * height).
```
