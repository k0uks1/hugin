# E0925: postulate not allowed with --safe

The program declares a postulate, and it is compiled with `--safe`.

## Example

```hugin fail=E0925 safe
eqn : nat -> nat -> Type.
same : eqn N N.
twoIsThree : eqn 2 3 = %postulate.
```

## Why this is an error

A postulate `x : A = %postulate.` is a constant without a value: it assumes that `A` has an element.
That is an axiom, and nothing checks it: `twoIsThree` above assumes a false statement, from which any
other follows. `--safe` (the option of `hugin check` and `hugin run`, the setting `hugin.safe` of the
language server) accepts only what the program proves, so it rejects every postulate of the program and
of the files it imports. The standard library has none. Without `--safe`, a postulate is allowed, and
`--print-assumptions f` lists the postulates that the meta constant `f` depends on. See
[Functions](https://k0uks1.github.io/hugin/reference/meta/functions.html#postulates).

## How to fix it

Prove the statement instead: define the constant by a value or by clauses.

```hugin safe
eqn : nat -> nat -> Type.
same : eqn N N.
twoIsTwo : eqn 2 2 = same.
```

Or compile without `--safe`, keeping the assumption visible with `--print-assumptions`.
