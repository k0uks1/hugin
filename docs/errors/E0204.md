# E0204: signature mismatch

An argument does not match the parameter signature.

## Example

```hugin fail=E0204
graph : mod = { node : type, edge : node -> node -> rel }.
tc (g : graph) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
  path X Z :- g.edge X Y, path Y Z.
}.
city : type.
road : city -> city -> rel.
weight : city -> city -> int -> rel.
bad = tc { node = city }.
```

## Why this is an error

A module passed to a functor must provide every field its parameter's signature declares, at the
declared meta types (missing fields, constructor arities and data versus `%fact` constructors are
compared). Extra fields are allowed.

## How to fix it

```hugin
graph : mod = { node : type, edge : node -> node -> rel }.
tc (g : graph) = {
  path : g.node -> g.node -> rel.
  path X Y :- g.edge X Y.
  path X Z :- g.edge X Y, path Y Z.
}.
city : type.
road : city -> city -> rel.
weight : city -> city -> int -> rel.
ok = tc { node = city, edge = road }.
```
