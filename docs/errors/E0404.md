# E0404: ill-formed declaration

A type declaration or subtyping edge is not well formed.

## Example

```hugin fail=E0404
shape : type.
circle : int -> shape.
small : type <: circle.
```

## Why this is an error

A refinement `a : type <: b.` must refine a base type or another refinement, without cycles. A
subtyping edge `c <: t` needs an open type `t` and a fact type `c`. The members of a union must be types
of facts and must not overlap.

## How to fix it

Refine a base type or another refinement:

```hugin
size : type <: int.
small : type <: size.
```
